## Shared core capabilities

Use one World, attached Grid and Random per model; Agent owns each mobile individual's coordinates/kind/state, Fields own all land/potential/utility caches. World.tick is the only scientific clock. Kind changes preserve Agent identity. Temporary activation snapshots/staged arrays/canonical-neighbor projections do not own a competing population or topology. Reads return deeply frozen detached records and consume no RNG; IDs are opaque.

Existing public closure: Grid.fields/neighbors/fieldAt/agentsAt/diffuse; Agent.create/move/rotate/distanceTo/copy/delete; World.create/agents/tick; run; Random.number uniform and sample; stats.histogram. Toroidal centers and hard geometry come from public Grid/Space, not a private offset/distance engine. Structure averaging should stage the explicit `(self+sumFaces)/5` expression to preserve its equation/grouping; it is not global normalization. Generic diffuse(rate0.8) is mathematically related but has a different floating operation schedule.

The shared normal sampler, statistical summary and pure spatial probes supply the reusable operations these models need:

| Requirement | Public API | Model responsibility |
| --- | --- | --- |
| Tijuana Gaussian samples | `random.number({distribution:"normal",mean,deviation})` | Preserve source tail/error behavior; never truncate or substitute a uniform draw. |
| Economic travel median | `stats.describe(values).median` | Select the exact source quantity and declare empty-report behavior. |
| Sprawl/Tijuana direction probes | `geometry.direction`, `geometry.normalize`, `geometry.distance` | Compose source predicates without temporary agents or a private geometry engine. |
| Tijuana preincrement and reset | `world.tick.advance()` and `reset()` | Advance before procedures, retain partial-error time, reset on completed cityscape. |

## Shared model conventions

Future modules export inputs,create(options={}),model following current Definition/parameters patterns. Seed1 is explicit target Mulberry replay, not NetLogo seed identity. Inputs/rules/fixtures validate completely before writes, reject unknown/accessor/nonplain/nonfinite/out-of-step data, and preserve tick/RNG/history on validation failure. Runtime errors retain their actual earlier committed phase effects; do not promise blanket rollback.

Read snapshots include tick,width,height,parameters,cells,history,randomState,done plus named reports. History is setup plus latest1000 completed scientific ticks unless the Tijuana epoch/reset contract below requires a separate cityscape record. Fixed dimensions are not speculative user knobs. Source setup-only sliders remain setup-only; genuinely live/cached effects are distinguished below. Fixture arrays follow canonical field order and retain Field IDs; agent replacement creates fresh IDs in specified insertion order. setRules is same-tick/no-RNG and does not retroactively reset counters or paint state.

### Structure from Randomness1

130×130 torus, source x/y0..129; centered target cell centers−64.5..64.5 on both axes (translate by64.5). Setup independently chooses from `[-1,1]`, then recolors and resets ticks. Only source input is live keep-adding-randomness? false. Proposed keepAddingRandomness camel-case input, plus target seed.

Go stages every new activity as `(oldSelf+sum(oldFourFaces))/5`. If adding noise, add an independent choice from `[1,-1]` to every staged value. Commit all activities, recolor, then tick. Do not sequentially update, use Moore8, normalize scientific state by its maximum, or interpret color scaling as domain rescaling. Without noise total activity is conserved within a declared floating tolerance; with noise total changes by the signed additions. Source display computes scale=max(abs(activity)) and colorNumber=`5+4.9*activity/scale`, giving relative grayscale. A nonzero field is necessary for that source recolor division; an all-zero injected field raises a source boundary to verify in the real browser. A target fixture may reject all-zero atomically as an explicit precondition rather than silently invent a guard.

Read cells activity/colorNumber, activityDistribution descending current16900 values (rank plot, **not histogram**), totalActivity,maxAbsoluteActivity. Proposed setActivities(exact16900 finite numbers with at least one nonzero), preserves clock/RNG and refreshes same-tick current report/colors. No source scientific terminal rule; uniform/stable fields still tick. Additional deterministic tests: corner impulse face wrap, conservation, no scientific draws when noise disabled, noise draws and bounds, all-zero error handling, read purity and independent instances.

### Structure from Randomness2

Same130² torus/translation. Setup potential from `[1,-1]` but leaves all patches black, even if initial potential exceeds a user-selected low threshold. Live threshold4.5,range0..10,step0.1. Every go stages `(oldSelf+sumFaces)/5 + one-of[1,-1]`, commits, and **only** makes a cell white when new potential is strictly greater than threshold; no later operation turns it black. Store canonical activated:boolean separately from potential. Lowering potential or raising threshold does not clear activation.

The Cells Above Threshold plot is the **current** count potential>threshold, not the monotonic activated/white count. Potential plot reports maxPotential and meanPotential×10; monitor reports unscaled mean. Preserve both units explicitly in read/history, e.g. meanPotential,meanPotentialTimesTen,maxPotential,counts.currentAboveThreshold,counts.activated. No feedback from the white marker to diffusion/noise. No terminal rule.

Proposed setPotentials(exact16900 finite numbers) changes potential only, preserving activated flags; setActivations(exact16900 booleans) is a separate explicit target fixture for resetting a display history. Neither draws RNG or ticks. setRules({threshold}) updates current reporters without repainting. Source/target histories may include the target's explicit setup sample; document plot timing/update differences instead of claiming equal curves. Test strict threshold ties, sticky activation, mixed-sign fields and distinct current/ever counts.

### Sprawl Effect

35² torus, centers−17..17. Defaults: smoothness15(integer1..20),maxAttraction15(integer0..30),population200(integer1..750),seekerSearchAngle84(integer1..360),seekerPatience60(integer0..120),waitBetweenSeeking15(integer5..60). Setup assigns each field integer random maxAttraction, repeats **Moore** diffuse0.4 smoothness times, colors green scale2.5..10, creates population seekers all at(0,0),source random integer headings,patienceCounter=seekerPatience. Cache buildThreshold=floor(maxAttraction/2) at setup.

Source random(bound) on a fractional attraction uses a bounded integer domain, not random-float×attraction; resolve exact ceil/sign/zero draw behavior from the official primitive binding/browser. Public uniform integer range can express the chosen domain once clarified; no private RNG engine. maxAttraction0 is a valid source slider position and must not be silently forbidden.

Go snapshots seekers and randomly activates each full procedure. wantToBuild is `random attraction >= cachedBuildThreshold OR patienceCounter=0`. On success mutate kind to house (same identity) and stayCounter=currentwait. Otherwise, only when patienceCounter>0: probe ahead1/right-angle1/left-angle1, prefer right only if strictly better than both ahead/left; else prefer left if better than ahead; right/left turn is integer random search-angle, not directly face best patch. Move0.5, decrement patience and add0.01 to the **destination** field. No decrease/stepping once patienceCounter is negative via a pathological fixture; source tests equality0, not <=0.

Then snapshot houses **after** conversion: newly built houses act immediately. Each sequentially adds0.05 if current attraction<=2*currentmaxAttraction; otherwise resets field0. Test is <=, so one addition may exceed the threshold before the next actor resets it. Decrement stayCounter; <=0 converts to seeker, resets patience from current setting and keeps identity/heading. New seekers from this house phase do not move until next go. Multiple houses share/update the same field sequentially; do not batch the field increment or impose one-house-per-cell. Recolor then tick; no scientific terminal rule/population turnover.

Live setRules accepts maxAttraction,seekerSearchAngle,seekerPatience,waitBetweenSeeking. maxAttraction changes the house degradation cap immediately on its next phase, **not cached buildThreshold**; existing counters do not reset. smoothness/population apply only next setup. Read agents kind/x/y/heading/patienceCounter/stayCounter,counts.seekers/houses,totalAttraction,buildThreshold,cells.attraction/colorNumber. Proposed setAttractions(exact1225 finite nonnegative values) and setAgents(typed seeker/house states), same-tick/no-RNG fixtures. Negative counters may be permitted intentionally only after explicit fixture validation policy; do not accidentally broaden normal input bounds. Use the shared pure spatial probes above.

### Economic Disparity

89² **hard** world,centers−44..44. Setup job at(0,0),all Fields price=quality40,sdDistance=nearestJobDistance (no0.01 offset initially). Create five rich then five poor at continuous x/y=`5-random-float10`; sequential residents immediately multiply price and quality in nested radius shells, so setup land is not uniform despite Info's initial summary. Store jobs/rich/poor as canonical Agent kinds, utility and age/insertion order on their owner; no separate breed registry or who-ID parsing.

Live defaults/bounds: numberOfTests15(integer0..30);residentsPerJob100(0..500 step10);poorPerStep5/richPerStep5(integer0..15);poorPricePriority0/richQualityPriority0(−1..1 step0.1);maxJobs10(integer5..20);deathRate4(integer0..15). View mode starts quality; source price/quality/distance/poor-utility/rich-utility buttons update the display immediately without a scientific tick.

Each go: increment counter by poorPerStep,create that many poor with complete evaluate→decreaseQuality→decreasePrice procedures; then increment/add/evaluate/raise rich. For each candidate search sample n-of **all** Fields first, then remove any with any turtle (including jobs or that new person's origin). Never resample until n empty candidates exist. Choose random among maximum-utility ties; move to center, store its utility. Poor utility is `(1/(sdDistance/100+0.1))^(1-poorPriority) * (1/price)^(1+poorPriority)`. Rich utility is `(1/(sdDistance+0.1))^(1-richPriority) * quality^(1+richPriority)`. Distance denominators differ by factor100. Empty candidates call STOP inside evaluate-*; exact caller/agent continuation, especially numberOfTests0, must be verified in the original browser before deciding target behavior.

Impact is cumulative nested shells around the **continuous agent location**, not disjoint annuli around rounded patch center: own patch×1.05 or0.95,then radius1×1.04/0.96,radius2×1.03/0.97,radius3×1.02/0.98,radius4×1.01/0.99. Clamp upper100 for rich/lower1 for poor only during the radius4 pass. For a resident at an integer center the center receives all five multipliers; generic diffusion is not equivalent. Price and quality undergo corresponding identical multipliers, not cash transfers; no wealth-conservation invariant applies.

If counter **>** residentsPerJob,attempt one new service and reset counter0 (discard remainder,even if no site); no while-loop or >=. Choose a uniform empty spawn patch,then a separate n-of field candidate set filtered after sampling and maximum **price** tie choice. Jobs do not choose nearest demand or minimum rent. After possible job addition, if rich count>=20 delete deathRate oldest rich; same for poor. Threshold20 is tested once,not a population cap; deletion order follows canonical insertion. If jobs count>=maxJobs delete **one oldest** job,so reaching max can leave max−1. Recompute every sdDistance after addition/deletion as nearest actual distance+0.01, unlike setup. Recolor/update-view then tick.

Source Travel Distance plots **median** actual nearest-job distances for rich and poor, although Info incorrectly says average. Do not report cached sdDistance (with its later0.01) as actual travel distance. Bind to stats.describe(...).median after its real public delivery. Normal slider closure retains people/jobs; injected empty populations/jobs and utility-log/zero-spread colors require explicit baseline/error or nullable target contracts.

Proposed public fixtures setAgents(readonly {kind:"rich"|"poor"|"job",x,y,utility}[]) (ordered insertion,finite inside hard half-open extent),setLand(readonly {price,quality}[]) (exact7921,[1,100]); refresh nearest-distance cache explicitly and record fixture adaptation. read exposes Agents/kind/utility,counts.rich/poor/jobs,counter,cells.price/quality/sdDistance/utility reporters,medianTravelDistance.rich/poor,viewMode/history. setViewMode invokes headless source-timed color/report update without ticking; price/quality scientific state is unchanged by view modes. This is a proposal pending stats/probe/source-STOP clarification, not an already working API.

### Tijuana Bordertowns

171×115 hard world,centers x−85..85,y−57..57. No external cityscape data; all elevation,roads,services,employment,settlements are generated. Source controls: clear;forever cityscape(setup);forever go;inspect;forever add-node;update-now. Defaults: maquiladoras8(1..8),serviceCenters3(1..3),migrationTicks3(1..20),crossingTicks15(1..20),initDensity0.7(0.5..1 step0.1),requiredCapital500(150..1200 step10),coloniaSize2(0..2 step0.25),carryingCapacity6(1..6),buildingTicks6(0.5..6 step0.5),cityGrowthfalse,colorCodetrue,visualUpdate"off" (also elevation,land value gradient,colonias,units with no water/units with no electricity). Setup-only versus live parameters need phase-aware declarations: sliders configure cityscape creation but many also affect later go; do not globally freeze them all as setup-only.

Source CLEAR clears state,paints white,resets ticks; it does not reseed. CITYSCAPE is **incremental**: guard already-completed with a user message/no tick; otherwise tick first,generate-cityscape,conditionally initial-condition and expansion,economics,then on thirdPhase"stop" round land values,reset ticks0,set setupDone true,stop forever host. A target may expose create() in cleared state,advanceCityscape(count=1),advance(count=1) for GO,clear(),addNode(position),setRules(),updateDisplay(); do not silently substitute a single generic growth step or unbounded hidden setup loop. Proposed clear retains World/Grid identities and RNG,removes Agents,resets fields/globals/World.tick,clears current history; factory reset with seed is a separately labeled host operation.

Cityscape phases, in source order:

1. First tick: elevation9.9 with2..5 random topographic nuclei; three noisy radius patches/faces; two thresholded smoothing passes; isolated-hole removal; one Moore diffusion1. Hard-edge missing slots matter. Initialize water10,electricity1,occupied"no",transport1.5. Sample interior service centers (|x|<65,|y|<37); raise nearby elevation9.9,radius20; provide local utilities; sprout normally distributed builder counts/headings/energy/block sizes and source pen traces. Orient one road per center toward another center where applicable.
2. Original builders move1,periodically random-normal heading,reduce weight0.02 rounded3,set landValue=12*weight,transport0.75,ctr markers radius8. At tick membership of blockSize×[1,3,7,10],hatch second-order builders left/right,energy integer random parentenergy. Check two-ahead hard/collision; source may advance before dying.
3. Second-order builders move0.5,write land=7*weight **before** clamping weight0,provide utilities,reduce energy by corridor/distance conditions (randomly selected service centers),turn using noisy rounded headings,die on energy/terrain/road/occupied-land/hard conditions. On random rounded-period divisibility hatch two third-order builders. New third-order builders enter the **later** ask in this same iteration.
4. Third-order builders move/write/degrade similarly,may supply radius2 power if weight>0.3,branch at normally distributed period,check terrain/roads/existing land/hard edge. Initial routines retain zero-energy builders as stopping markers; do not impose generic energy-death rules not present in their code. Remove all builder kinds on extreme patch coordinates. Recompute values/weights at source conditions.
5. When no first-order builders and at least one third-order builder with all energy0: seven Moore land diffusions1,clamp/round values,record marginal values/weights,delete third-order builders,adjust service display sizes,place maquiladoras. Warn if industrial candidates insufficient but still create requested count; missing sites leave centers at origin,then colocated employment-center deletion can reduce count. Employment patches set water/electricity/transport to **strings**"0.0",not numbers; preserve or explicitly resolve type-sensitive source behavior. Mark industrial neighborhood occupied"maquiladora".
6. Seed irregular lots by source criteria/availability near utilities and far from jobs. Fractional n-of floatingPopulation/5 needs official coercion clarification. Initial migrants have size0.65,origin state,canonical workplace reference list,resident age roundedNormal8,2. Expand one remaining0.65 migrant per setup call with up to four random nearby migrants of size0.6,each current-source job/cost/age; later asks color and write occupied origin. When no0.65 remain set thirdPhase"go".
7. Economics loops migrants sequentially,decreases colonia in radius4−coloniaSize/2,recomputes costs,maxCost,sets incomeNormal(maxCost,3) rounded2. For each income<expenses,subtract1 expenses repeatedly until affordable; this changes costs,not income/work/infrastructure. If none remain unaffordable set thirdPhase"stop";setup then resets World.tick and completes.

GO first guards setupDone; native user message/no tick otherwise. Then **tick before all rules**: refresh builder values/weights if any;maxCost over migrants;updateDisplay;round savings/expenses;migrate on tick% migrationTicks;write occupied origins;increment residency every15ticks;hide growth builders;optionally regulate then move/build at buildingTicks,and hatch left/right when tick%(2*buildingTicks)=0;clamp land/clear vacancy/normalize colonia;delete extreme-coordinate turtles;regularize;cross;earn-spend;move. A later error leaves the already advanced World tick and earlier changes,unlike default run's successful-after-step convention.

Preserve the procedure-specific details: migrate-static hatches a child at newcomer but then edits the **parent's** origin occupancy/shape/residence/cost/income/savings and colonia radius4−coloniaSize; do not silently move the parent instead. Cross deletes one uniform migrant at crossing interval and increments crossed1,not a percentage. Residency>5 and water==10 and savings>capital allows movement only to water2/electricity3/landValue<savings*0.0010; charge new landValue/0.0010 after moving. Regularize chooses qualifying colonia,at most5rings; ring size is squared mean colonia of migrants within10 divided3,with empty-mean potential errors; may spawn a third-order builder facing nearest migrant. Growth builder updates utilities/land/colonia along its route. Costs=land+power+water+27food+8other+transport*(distance random service/30+distance one assigned workplace/25); draw/tie choices are scientific and source strings can affect arithmetic.

**View changes can mutate scientific state.** updateDisplay in colonias mode changes every colonia0 to9.9 before coloring; the value is used by regularization/economics. It must be a public headless action/phase,not renderer-only code. Other modes intentionally leave some old patch colors unchanged; source-time color memory may matter for faithful interactions. addNode creates canonical node and changes service/land fields in carryingCapacity radius,using distance to nearest node and current weights/marginalValue; it is not cosmetic drawing. The model remains selected while its public Normal/spatial dependencies and actual source baseline are resolved.

## Source boundary rules

Structure1 all-zero recoloring fails after activity commit and before tick. The target fixture rejects all-zero input atomically; a naturally reached zero-scale step retains committed fields and throws before tick. Structure2 activation is persistent and its mean plot is scaled by ten.

Sprawl integer random uses ceiling for positive bounds. Exact zero returns zero without a draw; positive fractional bounds below one consume a draw. Search angle zero is invalid. Economic Disparity's helper stop returns from evaluation only: land impacts continue even with `numberOfTests = 0`. Job-cap removal at `>= maxJobs` applies without new jobs; counter creation uses strict `>`. Travel plots use agent-weighted nearest-job distance medians rather than the cached distance with its .01 offset.

Tijuana requires its own [full model contract](../../models/urban-suite-tijuana-bordertowns/contract.md) and substantive lifecycle examples; its cleared-state checks here do not replace that acceptance.
