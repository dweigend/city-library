# Probability and fractal model contracts

The fixed ten identities are `catalogPath` values in the batch ledger, checked against selection.json and inventory.json. Sources are exact served NetLogo 7.0.4 XML at Galapagos revision90be931773fcf499049247a8aaa1aecbe003654c. Full Info notices remain in each source and NOTICE.md. Scientific dossiers are existing contextual evidence, not execution validation.

Public model factories accept seed, provide detached read observations and explicit advance actions; zero steps preserve observations/RNG, invalid step counts fail. Original setup defaults, phase order, stop conditions and special actions are governed by each exact XML. Model-specific source semantics and adaptations are recorded in the first/last contract reports. No new core library expansion is authorized by these scripts: reuse the existing public Random, World, Grid and statistics contracts. Any required expansion must first receive its own four/five asserted scripts and separate review gate.

The existing defineUI contract provides parameter setup/live controls, actions, drawing and neutral views. Model logic owns state and all calculations. UI adapters only project detached observations and invoke actions. Existing APIs and README remain stable. No graph connectivity dependency is required for these probability/fractal models.
