# Observed numeric color binding for shared UI

Numeric NetLogo colors carry meaning in several adapted models, including the color memory and cycling in Cells. The shared `netLogoColor` UI helper maps those observed numeric values to CSS colors. Its [binding record](../../models/catalog/acceptance/urban-feedback-reference-evidence/color-bindings.json) pins all 1,400 observed RGB bins, source identity and lookup hash; the mapping does not copy engine code or introduce new scientific state.

The public examples in `tests/ui/ui-color/` cover the binding. Public `netLogoColor(color:number):string`, exported from ui/index.ts, returns lowercase #rrggbb. Require an actual number (TypeError otherwise) and finite value (RangeError otherwise). Normalize modulo140,adding140 only when the remainder is negative; look up floor(10*normalized) in the observed1400-bin RGB table. No interpolation, nearest-bin rounding, hidden state, DOM, clock or RNG. Retain table provenance/hash in the reusable ui/palette module. This is a UI binding, not a new scientific kernel or model-specific private library.

Palette facts and helper remain under ui/. Headless Cells owns source-timed numeric colorNumber and cycle action; UI only converts observations to CSS. Positive Feedback can use the same binding for9.9*activity; Path quality colors may use their actual source numeric expression. Adapters render domain observations, never recompute scientific state. Five examples cover official anchors, floor quantization, positive/negative wrap, detached field projection and strict invalid/large finite inputs. The example assertions remain compatibility requirements. Typecheck these UI examples with the UI DOM configuration, independently of the headless library config; runtime examples themselves need no mounted DOM.

Numerical boundary: IEEE addition can round a negative subnormal remainder plus140 to exactly140. Preserve the promised finite-number result by clamping that computed out-of-range bin to1399, the mathematical last interval below140. Normal observed bins remain unchanged; this narrow target numeric guard is explicitly not an observed source-engine behavior. Additional tests cover negative/positive Number.MIN_VALUE and negative zero without changing the frozen five examples.
