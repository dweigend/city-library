# Graph generators

Graph generators make repeatable starting topologies for an experiment. This contract covers the existing `Graph.generate` and `GeneratorOptions` API for eleven kinds: path, cycle, star, wheel, complete, tree, lattice, random, smallWorld, preferential and geometric. The public examples in `examples/graph-generators-proposal/` assert ordering, draw schedules and failure behavior.

## Ordering, validation and publication

- Preserve the edge order and stored endpoint direction below. Path/cycle follow supplied order; star center first; wheel rim then spokes; complete uses lexicographic node pairs/arcs; tree increasing child; lattice node order then x/y/z positive-axis encounters, retaining the first duplicate; geometric i<j. SmallWorld keeps original clockwise slots with final endpoints; preferential emits the lexicographic seed clique followed by new-node/choice order, storing attachments new→previous. Return actual committed identities in a frozen array, never cloned nodes or a topology-only surrogate.

- each SmallWorld decision uses current temporary topology while its old edge remains present. Exclude current neighbors including that old endpoint; eligible targets use supplied node order. Successful selection consumes one uniform index draw even for a singleton pool; no eligible target consumes none. Every original clockwise slot consumes its probability decision; do not reprocess new edges. Preserve exact edge count and source. Preferential follows the bound degree-proportional without-replacement schedule, one uniform draw per choice and batch degree updates; an equivalent prefix index may preserve exactly the same cumulative intervals and draws without quadratic scans.

- snapshot the input array/canonical membership and relevant topology. The selected induced region must be edgeless, including loops and either direction; external/crossing edges remain unchanged. Hold structural protection across planning callbacks while allowing reentrant pure queries. Participating Agent deletion or actual graph edits reject; no extra World ownership or shadow topology. Capture and validate each position immediately once in supplied order. Caller external effects and consumed RNG draws are not rolled back. Release only the operation's own read protection before the single owner commit; respect any enclosing query guard.

- require the existing library-issued Random identity; preserve continuation and Gaussian cache while consuming only scheduled unit draws. No duck-typed fallback, seed reset or implicit World stream. Strict own-data records/dense arrays, exact kind-specific keys, foreign/unknown own keys reject even undefined; applicable optional undefined means default. Wrong shape/type, nonmembership/duplicate nodes, representation conflicts and malformed keys throw TypeError; finite invalid ranges/caps throw RangeError. Reuse existing geometry scalar error classes. Validate structural write availability, shapes/domains/membership/induced emptiness, obvious counts, supplied stream and default-state clone validity before callbacks/draws. A structural guard may reject the attempted transaction before further validation; no error-order guarantee across otherwise independent invalid arguments is invented.

- caps apply to100000 selected nodes and1000000 newly generated edges per call, never total existing graph size or candidate trials. Count lattice edges after self/duplicate collapse. Reject known oversize deterministic batches before draws. Random probability1's exact output is also known and preflighted; probability0 still consumes all scheduled pair draws and may have more than a million candidates. For genuinely stochastic output, stop planning when the first over-cap edge is discovered; throw before publication, retaining draws already consumed. Do not finish irrelevant remaining trials after failure or silently install a smaller cap. The100000-node positive path and1000405-draw zero-output case are accepted performance obligations; no positive million-edge test is required.

- clone-valid defaults are checked before planning. Recheck referenced-component liveness and materialize independent edge-state clones after callbacks/planning, before any edge publication; no caller callback runs during commit. Failed batches leave existing/new topology and per-graph automatic-key counter unchanged, as existing rejected-insertion rules require. Do not promise gap-free global opaque IDs or rollback of external effects. The internal owner commit must avoid repeated whole-graph scans per new edge. No new public batch/transaction API or model-private generator library. A working internal guard/batch helper is permitted.

- reuse position, Space normalization, displacement and finite-distance rules. Without Space, measure ordinary Euclidean distance with the same finite-intermediate failure policy; with Space, use explicitly supplied boundary rules. Hard boundaries do not clip measurement endpoints. No World inference, coordinate magnitude cap, geodesy or epsilon radius. Inputs must have homogeneous finite XY or XYZ dimensions, inclusive distance≤radius; plain records and canonical Agent/Field positions follow existing geometry rules. Geometry/callback failure leaves the batch unpublished.

All declared kind-specific domains/defaults/caps in the binding remain unchanged. In particular, branching is a positive finite integer without an invented safe-integer cap. Empty/singleton path/cycle/star/complete and empty tree follow the binding; wheel/lattice/SmallWorld/preferential retain their explicit domains. Library return order and RNG do not claim native NW seed/creation parity. Source inward-wheel, directed growth/rewiring and Kleinberg laws remain separate model/extension questions, never silently substituted.
