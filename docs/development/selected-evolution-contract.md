## Source-specific semantics

- **Mimicry:** setup75 birds,225 monarchs,225 viceroys; carrying capacities75/225/225, reproduction chance4%. Each go birds move, butterflies move, predation, forgetting, reproduction, then tick. Birds remember only unremembered monarch colors that they eat. FIFO memory evicts oldest when length>=memory-size before append[color,0]. Forget first increments age then retains age<=duration. Reproduction uses live group count in `random count < capacity-count`, then4% gate; mutations select actual sublist base-colors1 10, i.e.15…95 (native reporter confirmed; comment15…105 is inaccurate). No extinction stop. Preserve exact default sliders in audit.
- **Anisogamy:** adults/gametes/zygotes remain separate canonical group states. Setup adults at trait.25, lifetime normal(500,50); provisioning.5, spawning1.5%. Whole-tick test is floor(t)>floor(t-previousDelta); adults move/spawn/age and zygotes incubate/become adults only at that gate; capacity culls adults there. Gametes move/fuse/age every partial call. Diameter2sqrt(mass/pi), offspring number floor(.5/instantaneous mass), viability thresholds inclusive. Neighbors plus own patch identify touching candidates, strict distance<(diameter sum)/2; optional same-type exclusion. Fusion consumes both gametes even when zygote below threshold, inherits one bundled parent strategy. Partial delta=min gamete diameter / maximum diameter, empty1. Advance fractional tick after all actions; extinction stop afterward. Restore defaults is a public parameter action. Normal RNG already exists; exponential/Poisson are not needed by these Procedures.
- **Peppered Moths:** each old moth mates first at age2/3(hatch2), suffers random1/13 death, live population>4*mothCount overcrowding death1/2, camouflage death(random-float1000 < selection*abs(envColor-color)+200), then ages. Newborns do not run this ask. Mutation uses signed random amount mutation/12.5, rounded and clamped1…9. Optional pollution cycle precedes tick; monitor counts update after tick. Darkness0…8, envColor9-darkness, speed/100; endpoint direction changes only on a failed next action. Pollute/Clean-up are non-ticking live actions. Empty population still ticks.
- **Baldwin Effect:** three independent populations with shared target binary phenotype. Plastic genes'x' become random bits. Fitness normalized Hamming agreement, zero below1-smoothness, equality accepted. Random/smart learners retain only strict improvements and average best fitness over trials; smart retention probability is current best fitness. Each population learns, removes worst20%, then reproduces20%. Tournament samples30% of current group, weighted-n-of2 without replacement via public Random.sample(weight). Uniform crossover; mutation rate/1000; newborn fitness is inherited from chosen parent rather than recomputed before next generation. Rounded source repeat/n-of counts and ties need native probes. No terminal stop.
- **Mammoths:** embedded resource americas.png is domain input imported as patch colors, not decoration; retain resource bytes and establish exact source land mask before claiming map parity. Setup colors non-blue continent green; create mammoths on land and humans on land with pxcor<=10. Climate turns green to green+3 first; mammoths move/reproduce, humans settle/face/move/hunt/reproduce; natural deaths then all ages+1, tick. Human hunt shared draw: <3 human dies, otherwise <3+odds kills mammoth. Land-ahead excludes ocean/outside; repeated±10-degree search is source behavior. Density counts same group in own+8 neighbor patches divided9. Death age thresholds strictly>600/360 months, crowding>.75/.50, distinct climate counter, background.33%. Empty world still ticks. Native image import/resampling/classification must not be replaced by a hand-drawn map.
- **Sex Ratio Equilibrium:** setup round(ratio/100*initialSize) males, remaining females, normal traits clipped0…1 and truncated normal ages/longevity. Running average/SD return'NA' until history length>1000, then last1000; empty-sex mean reporters may throw natively and require documented scenario.
- **Bacterial Infection:** two regions separated by walls; defaults4 of each variation3…6 per region. Setup bacteria ages=reproduceEvery*60. Reproduction snapshots eligibility against total count, then live available same-region neighbors; child target reservation stores parent reference in source, and bacteria-death tests `is-patch-set?` on a patch (likely never clears reservation). Preserve this quirk pending native probes. Move toward target at.015 when distance>.2, resetting age then increment; antibiotics move.2 and bounce against wall patches. Reproduce switch is live. Fever source global defaults false. Minutes=ticks, hours=floor(ticks/60), days=floor(hours/2.4)/10. No extinction stop.
- **Vision Evolution:** pre-step no-fish stop. Each fish moves, consumes energy, eats one same-patch food, dies at energy<0, reproduces; then food replenishment and tick. y<0 is water for vision/energy/movement, despite background pycor<=0 water. Move step water1-mobility/land mobility plus U[0,.1); closest weighted prey within radius, random tie. Energy abs(mobility*10-.5) water or abs((1-mobility)*10-.5) land plus abs((eye-1)/(11-eyeCost)). ## Delivery gates

Exactly five scripts cover all ten, pure source equations, initialized populations, read purity/detachment, actions and terminal/tick boundaries. Broader behavior tests complement them. Do not weaken frozen assertions to accommodate runtime. A missing reusable capability needs its own public contract and examples; do not replace it privately in a model. Mammoths uses a source-native static mask for all 9409 fields, with no runtime importer. See models/mammoths/data/README.md and selected-evolution-evidence/mammoths-mask-verification.json. Independent review is required for model acceptance.
