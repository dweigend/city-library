# Direction, normalization and distance

A model can probe a direction, normalize a position or measure a distance without temporarily moving an agent. The three public operations are `geometry.direction`, `geometry.normalize` and `geometry.distance`. They reuse the spatial rules of Agent and Grid while owning no model state, clock or random stream. Sprawl and Tijuana provide the concrete use cases.

geometry.direction requires finite heading;optional finite pitch determines XYZ (even zero),otherwise XY. Validate supplied finite roll,which does not change forward. Interpret the binding's explicit XYZ pitch requirement and prohibition on silently ignoring an XY roll as:roll without pitch rejects;pitch0 with roll is validXYZ. This is a documented binding resolution,not an invented new parameter. Return detached frozen unit vector(sin heading*cos pitch,cos heading*cos pitch,sin pitch) in degrees;XY omitsz. Reduce finite angles modulo360 before trig to avoid overflow for huge finite angles. Standard transcendental rounding uses tolerance,not native StrictMath bit identity.

geometry.normalize uses existing normalized-space/position helpers and canonical wrap/boundary rules,validating complete inputs/options before outputs. Wrap axes into centered half-open interval;hard axes reject outside by returningundefined. Endpoints defaultclosed so positivehard endpoint remains valid;half-open excludes positivehard endpoint but retains negative endpoint. XY/XYZ mustmatch context,including explicitz0invalidinXY. Normalize owns no state and mustnotmove/clip/clamp Agents. Returned data detached/frozen;input/contextunchanged,zeroAgent/World/Gridallocation,zeroRNG/tick. Validate wrongshapes/unknown/accessor options/domainerrors consistently withboundspatialAPIs.

Publish frozen geometry namespace and function signatures through rootindex,with implementationunder src/geometry/. Reuse existing private primitives rather than changing Agentmovementorintroducinga reciprocal Agent dependency. Public examples in `tests/public-contracts/probes/` cover: XY heading/XYZ pitch+roll;mixwrapped/hard endpoints;3D/dimensionerrors;nonmutatingaheadprobecomposedwithpublicAgent/Grid;validationandinputpurity. Tests should compare againstexisting Agentforwardmovement and Gridlookup,periodicity/idempotence/mixedaxes,finitehugeangles/accessors and no-state/RNGeffects. Accepted examples stayunchanged.

Distance also uses complete finite position/context validation and returns a finite Euclidean norm. Default wraptrue applies configured wrap axes only;wrapfalse takes direct displacement. Preserve existing half-extent tie conventions and require matching dimensions. Measurement points may be outside hard bounds;do not normalize,clip or move them. Accept canonical positioned Field/Agent references through existing position helpers as well as valid plain snapshots. Use finite Math.hypot so intermediate squared terms do not falsely overflow;reject nonfinite displacement/result. No allocation/mutation/RNG/clock. Five separate tests/public-contracts/distances cover3-4-5,outside-hard measurements,mixedwrap/direct,XYZ/errors,canonical Field→Field probes and validation/noRNG. Direction and normalization examples remain regression requirements.
