## Architecture and public surface

All factories export `inputs`, `create(options?)` and `model`. All instances expose validated `advance(count=1)`, atomic `setParameters(partial live options)` and detached, recursively frozen observations through `read()`. Only existing `city-library` public Agent, World, Grid, Graph, Random, geometry and run are imported. Domain logic has no UI/browser imports. Random selection and shuffles use the public Random stream. There is no copied RNG, transpiled NetLogo, private generic runtime, duplicate occupancy index or alternate domain-state owner. Model-specific arrays hold histories and reporter records; canonical agents own individual scientific values, Graph owns network membership/edges, and Grid owns cells/topology/occupancy queries. Source coordinates for noncentered worlds are translated at the public snapshot/presentation boundary.

Every UI has exclusive setup-only and live fields, calls public actions for writes, and re-exports `model` plus a sourceMarker containing its immutable source SHA. Shared host controls provide Setup/Step/Run/Pause; repeating Setup reinitializes with current field values. There is no separate Reset button. Minimal shared UI chrome is reused; scientific colors describe product, grammar state, citizen activity, sex/group membership or group tags/strategy. No new CSS or component system is introduced.

### Consumer Choice

The complete natural factory creates its social graph by repeatedly choosing a consumer and its nearest unlinked neighbor, preserving random ties. Source consumption and utility updates are separate shuffled phases. Satisfaction is recomputed only during consumption, so a live quality intervention leaves old satisfaction until the next choice. Utilities combine retained personal experience, optional neighbor quality information and current neighborhood norm fractions. read exposes consumers including satisfaction/experience/utility vectors, canonical link snapshots, orange/blue counts, average same-choice clustering and initial/progress history. `setParameters` accepts only normInfluence, informationExchange, exploration and both qualities.

The original can loop indefinitely when requested links exceed the complete graph; the target rejects that impossible setup before RNG/state creation. Empty-population clustering is null instead of division by zero. Links use a neutral contrast-preserving stroke rather than reproducing the source's exact scale-color formula. Product-dependent glyph size, product colors, both source plots and consumer inspection remain available. No scientific trajectory claim follows from source-like plots.

### Party

The canonical mixed-boundary World/Grid retain source group-site positions and complete source stacking movement. Agent group membership corresponds to source my-group-site, distinct from its stacked display coordinates. Happiness is recomputed before migration and intentionally remains stale after migration; preflight stop uses that stored state before applying changed tolerance. Groups wrap horizontally while vertical stacking uses hard boundaries. Empty groups do not count as single-sex. read exposes people, positions, group composition/counts, happiness, single-sex-group counts and both source plot histories. `setGroups` atomically validates complete own-data nested arrays, reconstructs canonical agents, recomputes happiness/stacking and resets tick/history. Invalid input leaves state, time and RNG untouched. A successful setGroups does not reseed the stream; source-like stack-order shuffling consumes draws. If “retains RNG” in the preliminary contract is intended to mean unchanged continuation rather than retained stream, that wording needs an explicit reconciliation before final acceptance.

The native empty Party setup fails in the Number Happy plot because it attempts SET-PLOT-Y-RANGE0 0, as observed by the coordinator. The target supports empty population with finite empty charts and a preflight stop; it does not claim source error equivalence. Sex colors and group count labels retain their functional meaning with shared simple glyphs in place of source person shapes.

### Ethnocentrism

All phases are implemented: optional full/empty setup, immigration into canonical empty cells, reset PTR, directed von Neumann interactions, snapshot-parent reproduction, independent offspring tag/trait mutation, mortality including offspring, then current/cumulative/last100 measurements and tick. PTR is deliberately not clamped; a fully cooperating occupied neighborhood with gain1 can yield PTR4. Setup actions clear canonical membership, counters, moving-window records and tick while continuing the source-like random stream.

read exposes all agents/tags/cooperation booleans/PTR, `turn` and `cumulative` encounter/cooperation counters, `turnRatios` and `cumulativeRatios`, `last100` records and `last100Ratios`, current `genotypes`, last100 `genotypeMean`/`genotypePercent`, and per-tick population/genotype histories. These represent all source BehaviorSpace reporter families, preserving max(1, denominator). The source's CC/CD/DC/DD plot is present. The renderer's available circle/triangle and size distinction plus CC/CD/DC/DD labels/inspector replace four filled/hollow source glyphs, retaining tag colors separately from cooperation strategy.
