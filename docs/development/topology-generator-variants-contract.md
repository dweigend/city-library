# Ordered topology generation

The delivered `profile:"ordered-topology/1"` selects the ordering, validation and random-draw rules defined below. It does not establish any model or stream equivalence.

## Public vocabulary, edition and ownership

Use opt-in **profile:"ordered-topology/1"** on `Graph.generate`. This selects the explicit topology rules below. Source provenance is retained in the dedicated source audit. New branches:

- kind:"kleinberg", required profile, nodes, shape:[columns,rows], clusteringExponent, random; optional wrap/directed false.
- kind:"preferential", required profile, nodes, edgesPerNode, random; optional directed false.
- kind:"small-world", required profile, nodes, neighborsPerSide, probability, random; optional directed false.
- kind:"wheel", required profile, nodes; optional directed false and spokes:"in"|"out", default in.
- kind:"lattice", required profile, nodes, shape:[columns,rows]; optional wrap/directed false.

Extend existing GeneratorOptions union only; retain the same readonly Edge result and one actual Graph owner/guard/atomic publication. Profile is a REQUIRED discriminator for these branches: an own undefined/unknown profile throws TypeError; unprofiled existing branches retain their old closed schemas, domains/defaults, parameter meanings, directed restrictions, ordering and draw schedules. Other optional recognized undefined fields mean omission. Wrong/inapplicable fields reject before draws; do not accept neighbors as a profile alias for neighborsPerSide. No profile for path/cycle/star/tree/complete/random/geometric is introduced. Existing inward-star/copy, undirected stored-endpoint and reordered generic outward-wheel compositions remain ordinary public operations; no redundant private generator engine.

## Shapes, numbers and caps

Both profile lattice/Kleinberg axes are finite integers>=2 with product equal to selected-node count. Row-major means x-fastest, index=row*columns+column. Wheel has at least4nodes. PA edgesPerNode is an integer1..n-1. WS has positive n, neighborsPerSide an integer0..floor((n-1)/2), probability finite[0,1]; n1/n2 k0 is valid. Finite scalar validation follows the existing generator TypeError convention, numeric-domain violations RangeError. Flags are booleans. Directed PA/WS is legal only in these opt-in branches.

Reuse the exact existing entry snapshots/canonical-node membership/induced-edgeless/default-clone/reentrancy/liveness contracts. Inherit100000 SELECTED nodes and1000000 NEW edges, never total-Graph or candidate-work limits. Preflight deterministic output bounds before any draw, including PA seed+growth and WS n*k; no hidden new cap. Wheel/lattice are deterministic. Kleinberg has at most base+n new edges, within the existing cap for admitted nodes. Rejection trial work is not output size. No arbitrary PA/WS retry cap or shortened stochastic protocol. Failed planning/cloning publishes no edges and does not advance automatic key cursor; consumed Random draws are retained as before. Use efficient existing owner batches, not repeated public edges.add scans.

## Operational topology and portable RNG

Use only the explicitly supplied real library-issued Random. Integer selector means exactly one existing unit double mapped by floor(U*remaining), including singleton remaining; endpoint choice consumes a separate unit and chooses end1 for U<.5, otherwise end2. These are portable Mulberry continuation rules, NOT native bounded-int/boolean bit schedules. Preserve any Gaussian companion; no extra stream/cache/World inference or hidden draws.

**Lattice:** visit source rows/columns; emit right then down, including the last-to-first seam only if that axis length>2. Stored undirected endpoint order follows emission; unordered duplicates suppress without endpoint reordering. Directed two-cell axes therefore do not receive generic antiparallel seam arcs. Generic lattice stays unchanged.

**Kleinberg:** first build that profile lattice. For each source in row-major order, consider EVERY other target in row-major order, including current neighbors. Distance is Manhattan; wrap uses the minimum absolute axis distance. Compute weight=Math.pow(distance,-clusteringExponent), cumulative Number sums in target order; one unit draw per source when total>0, pick=unit*total, choose first pick<=cumulative, final candidate fallback. One attempt/source; an already-present ordered pair (directed) or unordered pair suppresses the new edge without redrawing. Base emissions precede surviving shortcut attempts. clusteringExponent is required finite>=0, with no invented UI10/general cap. Since distance>=1, weights are finite in[0,1] and admitted lattices have positive total from distance1neighbors. Explicitly preserve binary64 underflow/flat CDF increments and the inclusive zero-boundary behavior, even at extreme exponents; do not replace them by exact fractions, epsilon selection, neighbor exclusion or guaranteed-success shortcuts. Ideal real-law probabilities are explanatory, not a claim of exact arbitrary-tail probabilities on a quantized portable stream.

**PA:** first m+1nodes form one seed edge i->j for every i<j; stored endpoint order remains this for undirected too. For each later node, sample a stored existing link and then one endpoint per attempt. Reject already-chosen targets, consuming both selectors again. Pool stays fixed until all m distinct choices are complete, then append new-node->old-target edges in choice order. Incident link ends supply the weighting even for directed edges; do not substitute in/out-degree or one-CDF-draw generic PA. Seed-only cases have no headless topology draw.

**WS:** preload all forward seed slots source i/offset1..k with target(i+offset)%n and symmetric neighbor occupancy, even for directed output. Each slot consumes one probability decision. If rewiring, remove its old neighbor before searching, so the old target is eligible. Reuse one initially node-ordered candidate buffer across ALL slots. For each rewiring reset cursor=0. Choose j=cursor+floor(unit*(n-cursor)), read the candidate at buffer[j], swap buffer[j] with buffer[cursor], then increment cursor. Reject self or either-direction existing neighbors and continue, otherwise accept. Even the final singleton trial consumes one unit. Persist that buffer permutation into subsequent slots; only the cursor resets. This is the source Front-Cursor protocol, not a Remaining-Tail shuffle. Update adjacency and slot endpoint; publish final edges in original slot order, not later link-creation order. k0 consumes no units. Complete underlying graphs can reselect only the old endpoint; do not optimize away required selectors.

**Wheel:** first n-1nodes form ascending rim cycle, last is hub; emit rim before spokes. Spokes in directs rim->hub, out directs hub->rim; directed rim keeps its ascending direction in either case. Undirected stored endpoints follow the same emission. Default in follows source. Whole-wheel reversal is not equivalent to selectively reversing spokes.

## Model actions and functional comparison boundary

The public examples separate birth, topology, block and layout policies. These library compositions do not establish full model equivalence. Native PA interleaves birth RNG and attachment; existing-node Graph.generate cannot reproduce that by one shared seed. A selected NW port may explicitly use a batch birth policy and portable stream schedules with documented functional/RNG differences, as earlier ports do; it must still preserve source preflight, node/state rules, actual actions/reporters/terminal conditions and prove its own original/target comparison. No native draw/trajectory or distribution-equivalence claim is allowed. Source birth/color/heading, native shuffled/no-op blocks, clear/append, layout, plots and host I/O stay model/host responsibilities, with actual source bugs/errors declared. Do not hide them in generate or call the profile a universal adapter.
