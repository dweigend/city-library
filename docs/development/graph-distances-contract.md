# Graph distances and summaries

Network experiments need distances and summaries that use the same canonical nodes and edges as the rest of the model. `graph.distances`, `graph.allDistances` and `graph.distanceSummary` provide those shared calculations. [The routing specification](../agent-loom/api-reference.md#graph-weighted-routing) defines the public API; the rules below fix algorithm choice, negative costs, disconnected nodes and measurement behavior.

## Behavior

`distances({from,cost?,algorithm?})` returns detached `ReadonlyMap` shortest distances from a current canonical node. `allDistances({cost?,algorithm?}?)` returns every source in node insertion order, including isolated nodes. Algorithm union is exactly auto/breadth/dijkstra/bellman-ford. Defaults:auto, unit edge costs; auto chooses breadth without explicit cost and dijkstra otherwise. Breadth rejects explicit costs. Explicit Bellman–Ford accepts finite signed costs; auto/dijkstra reject negative values even on unreachable edges. A reachable negative cycle throws RangeError; allDistances rejects a negative cycle anywhere. Undirected negative edges induce a cycle. Actual edge direction and parallel edge identities are honored; unreachable nodes are omitted, source distance0 retained.

`distanceSummary({cost?,disconnected?}?)` accepts finite nonnegative costs and defaults to reachable pairs. Mean uses ordered distinct reachable pairs; eccentricity is maximum finite outgoing peer distance or0, diameter/radius are max/min eccentricities. Empty graph has absent scalar summaries and empty map; singleton has mean absent, radius/diameter0. `disconnected:'reject'` throws RangeError for any missing distinct pair. All costs are captured once per edge in insertion order for the **whole top-level query**, including all-pairs/summary, not once per source. No cached mutable weights or RNG use.

Callbacks are caller-pure: structural mutation must be rejected by existing graph collection guards; returned thenables/nonfinite/nonnumeric values reject, callback exceptions propagate. Direct custom-state writes remain caller-owned violations and are not rolled back. Endpoint/option errors fail before invoking costs. Readonly result maps are detached observations; they may reference original canonical keys but own no topology/state. TypeScript readonly is required; no frozen result can be a mutable graph cache. Inputs use existing strict own-data option validation. Unknown fields, invalid algorithm/endpoint/callback types fail TypeError; finite-but-negative unsupported costs fail RangeError; nonfinite costs fail TypeError. Nonfinite accumulated distance arithmetic throws RangeError rather than emitting infinity or clamping. These numerical/error boundaries close previously implicit implementation cases, without adding a convenience operation.
