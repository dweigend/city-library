# Graph analysis

Graph analysis turns a topology into measurements a model can observe. This contract covers the existing `graph.analyze` signature and all five measures together. The [API reference](../agent-loom/api-reference.md#graph) specifies direction and incidence conventions; model-specific display choices remain outside the shared calculation.

## Numerical and callback rules

- Capture the selected pure cost/weight callback once per original current edge in insertion order, across the entire operation. Reverse arcs reuse captured values. Guard structural mutations and propagate the original thrown exception. Validate own-data option shape, measure-specific allowed keys and values before callbacks, including empty graphs. Inapplicable or unknown own keys reject even with undefined; applicable undefined fields use defaults. Valid empty graphs return empty maps and call no callbacks. Wrong types, nonfinite numbers/thenables and malformed keys throw TypeError; finite unsupported ranges throw RangeError; iterative nonconvergence throws Error without a partial result.
- Degree uses exact sums of captured binary64 incidence weights. Check and round the raw score nearest/ties-even to a finite Number before ordinary normalized division by max(1,n-1). MAX+1 is finite-rounded and allowed; MAX+2^970 throws before normalization. The divisor3 fixture explicitly distinguishes this publication rule from rounding a single exact normalized quotient.
- Closeness and betweenness use exact captured dyadic positive path costs and exact ordering. Reuse delivered routing arithmetic; published equal Numbers must never define predecessor equality. Every examined relaxation candidate must round finite, including discarded candidates. Closeness sums published distance Numbers exactly, using distanceSummary's finite cumulative boundary and one total rounding, then ordinary ratio/discount arithmetic. Total or ratio overflow throws before a later factor can hide it. No epsilon, minimum cost or graph/path cap.
- Betweenness counts parallel-edge paths with BigInt multiplicities. Dependency fractions and cross-source sums remain exact reduced rationals through undirected halving and normalization. Round only final node scores nearest/ties-even. Huge multiplicities alone are not errors; true final underflow may round to zero, but premature quotient underflow may not erase a representable final score. All input nodes receive scores, including isolates. Positive loops cannot be shortest vertex-simple predecessors.
- Eigenvector: structurally edgeless graphs return zero; present edges with all weights zero retain the uniform unit-L2 start under(A+I). Undirected loops supply two incoming arcs. Preserve the entire shifted operator when scaling, including the identity term. Accumulate each incoming dot product plus identity from the exact dyadic captured weights and current Number vector, then scale together and use stable L2 normalization. This prevents per-edge scaling from erasing or misrounding collectively representable tiny contributions. The tiny parallel-edge fixture has second normalized component exactly2MIN at the specified two-iteration stopping point. No clamp/epsilon or artificial zero is allowed. Iterates remain Number-valued; the specified L1 change criterion is not a universal true-eigenpair error guarantee.
- PageRank: undirected loops supply two outgoing arcs, with loop multiplicity relative to other edges preserved. Form transition probabilities by stable row normalization of the captured nonnegative weights, permitting well-defined MAX+MAX rows. Zero total rows are dangling. Iteration is Number-valued, with stable accumulation, uniform teleport/dangling mass and the specified L1 stopping rule. Representational rounding/underflow of extreme transition ratios is ordinary binary64 arithmetic; this is not an exact stationary-solution guarantee. No epsilon truncation, score clamping, new node cap or partial nonconverged vector. All final scores must be finite and mass normalization must preserve the stationary-probability meaning.

All results are detached insertion-ordered ReadonlyMaps keyed by canonical nodes. No RNG/model time/state mutation or hidden topology. Degree/centrality weights and iterative values have different declared publication stages; do not impose degree's raw-overflow boundary on a well-defined spectral probability/operator normalization.
