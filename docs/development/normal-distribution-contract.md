# Cached normal draws for the existing Mulberry profile

Normal draws belong to the shared random stream so that copying, reseeding and continuation reproduce the same experiment. `random.number({distribution:"normal",mean?,deviation?})` uses the standard Mulberry profile and retains the cached standard-normal companion in the existing `continuation.gaussian` field. The rules below define the draw schedule, validation and overflow behavior.

Mean defaults0,deviation1;finite mean/deviation>=0. Validate complete distribution-specific data before consuming word/cache; reject wrong/unknown keys/accessors/invalid types. Deviation0 returns mean without draws or draining a pending companion. Cached polar algorithm: generate x=2U−1,y=2U−1 until0<s=x²+y²<1;factor=sqrt(−2log(s)/s);return x*factor,cache y*factor. Cap at1000000 attempted pairs,throw after consumed draws on exhaustion. Consume a cached standard z before another raw draw;uniform/sample interleaving does not erase it. Return mean+deviation*z and reject nonfinite output AFTER consumption,without rollback. No tick/World/renderer effect. No MT profile,rawGaussian,other distributions or unrelated local-scope contract changes are delivered.

Public examples under `tests/public-contracts/normal/` cover: affine standard draws;cache/copy/serialized continuation and uniform interleave;zero-deviation/invalid atomicity;local/reseed continuation;post-consumption output overflow and unchanged uniform stream. Preserve accepted syntax and expectations. Tests should independently exercise polar rejection/order,finite deterministic moments as a sanity check,validation/accessor safety,nested local cache restoration and consumer API. Mathematical transcendental outputs use justified tolerance; never claim native NetLogo/StrictMath bit equality. Existing state snapshots and all earlier examples must remain compatible.
