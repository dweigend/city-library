# Selected cellular B19: spatial rules and moving heads

Author implementation evidence for SmoothLife, Hex Cell Aggregation, Vants and Turing Machine 2D. These are four of the fixed nine remaining B19 models; Life is excluded. Canonical paths, exact served-source URLs, SHA-256 pins, full Widgets and Procedures are in [the frozen source audit](selected-cellular-plan.md). Each experiment retains the exact archived `source.nlogox` and complete attribution/license in `NOTICE.md` (CC BY-NC-SA 3.0). No new literature research was performed.

The public model entrypoints are `experiments/<slug>/model.ts`. The implementations import the actual public `city-library` exports and shared experiment parameter descriptors; no private core imports, new dependencies, transpiled NetLogo, separate engines or unrelated experiment runtime are used. Each model has one World and one Grid; Vants and Turing heads are canonical public Agents admitted to that World. UI files import their model entrypoint and `ui/index.ts` only. UI colors and display shapes are presentation projections, not scientific state.

## SmoothLife

The production default is a 128×128 periodic grid, inner radius 3 and outer radius 9, with independent initial `U[0,0.75)` cell values. The centered Grid translates source coordinates `0..127` to `−63.5..63.5`; relative distances and topology are unchanged. Dimensions are configurable for public fixtures. The source's values are continuous but time is discrete: no continuous-time derivative, Euler increment or invented integration timestep is introduced.

Setup enumerates every unique periodic displacement once. Public `geometry.distance` supplies the actual toroidal Euclidean distance and public `Grid.fieldAt` supplies the canonical cells. The inner disk contains self and every distance `≤ innerRadius`. The annulus contains distances `> innerRadius` and `≤ outerRadius`. At default dimensions/radii the normalizers are **29** and **224**. Tiny wrapped worlds do not count duplicate periodic images. Empty annuli, equal/reversed radii, non-finite values and invalid parameter ranges are rejected before stepping, replacing the original's possible division-by-zero failure with a setup error.

`go` gathers each neighborhood's old values with the source cutoff: only values **strictly greater than `1e-4`** contribute to the numerator; every neighbor remains in the denominator. Source scatter accumulation and target gather accumulation implement the same normalized equation; field-order summation can differ by floating-point roundoff from NetLogo ask order. Every result is computed before any cell is written. `transition` and `sigmoid` are public named equations. Inner filling interpolates birth/survival interval endpoints through the inner sigmoid; the product of rising/falling outer sigmoids yields the next state. There is no binary-Life substitution.

## Hex Cell Aggregation

Defaults preserve the source's **101×101 bounded** world, one living center seed and all six neighbor switches on. Only odd dimensions are accepted because the source uses integer patch coordinates, an exact center seed and even/odd column parity. Every Grid cell owns its living flag, live-neighbor count and eligibility flag. The derived eligible Set and neighbor references contain canonical cell identities; they do not own a second population or cell-value store.

`hexNeighbors` composes source-specific offsets through public `Grid.fieldAt`. Even x-columns are displayed half a row lower and use `[(0,1),(1,0),(1,−1),(0,−1),(−1,−1),(−1,0)]`; odd columns use `[(0,1),(1,1),(1,0),(0,−1),(−1,0),(−1,1)]`. Out-of-bounds neighbors are absent. These are six actual reciprocal hex neighbors, not square-grid Moore or von Neumann neighbors. The center seed initially creates exactly six eligible cells when switch 1 is accepted.

| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| setup / setup-grid                     | Host Setup/Reset; dimensions and seed are explicit target fixture/reproducibility inputs.                                                                                                                         |
| six neighbor switches                  | `setSwitches(patch)` updates pending switch values only, matching the original requirement to press read-switches/setup.                                                                                          |
| read-switches                          | `readSwitches()` applies pending controls; `readSwitches([1,...])` explicitly applies a validated set of counts 1..6 for headless scripts. Empty accepted counts are valid and stop growth.                       |

The source's eligible-list insertion/ask order is replaced with a Set and uniform `Random.sample`; the mechanism remains one uniform eligible cell per step, but no matching stochastic trajectory or distribution-study result is claimed. Cells with six live neighbors display red, including a cell that becomes visible later, as the source's color update implies. The available shared renderer supports circle/triangle markers, so the thin target UI displays live cells as **staggered circles**, preserving the source display coordinates and hex adjacency. Hexagonal polygon glyphs are a declared presentation adaptation, not implemented shared UI functionality.

## Vants

Defaults preserve **241×241 periodic** white tape, one head at the origin and a uniform cardinal initial orientation. The target permits 1..16 heads, as the source num-vants slider does. Dimensions must be odd to preserve the exact source lattice origin. Binary tape state belongs only to Grid; who order, position and orientation belong to public Agent objects.

`goForward` processes ascending creation/who order: move forward one cell, toggle the destination tape color and turn right on white→black or left on black→white. `goReverse` processes descending who order: perform the same color-conditioned toggle/turn at the current cell, then move backward one cell. Both directions add one tick, matching the source. Head movement uses public Agent movement, Grid lookup and snapping to the canonical cell center. Cardinal orientation is rebased with public `Agent.rotate({towards})` instead of accumulating floating drift. This preserves exact reversible lattice behavior without maintaining a shadow position or orientation.

| Source widgets/procedures | Public target behavior                                                                                         |
| ------------------------- | -------------------------------------------------------------------------------------------------------------- |
| setup / num-vants         | Host Setup/Reset and setup-only `numVants`, width/height/seed.                                                 |
| forward forever           | `advance(count)` and host Step/Run/Pause.                                                                      |
| reverse forever           | `reverse(count)`, Reverse step and Run reverse repeated action.                                                |
| turn                      | Named source-conditioned `turn` composes the canonical tape and Agent orientation; no random activation order. |

Initialization uses public Mulberry cardinal draws instead of NetLogo's create-turtle random heading/color plus `face one-of neighbors4` schedule. After setup the model draws no randomness. No RNG-seed equivalence is claimed. Vants are red directional triangles; source turtle size is a display property, so target screen-space glyph size is explicit. `read()` snapshots retain canonical IDs while detaching all state. There is no scientific terminal condition.

## Turing Machine 2D

Defaults preserve **151×151 periodic** off tape, 32 heads at `(0,who)` with wrapping, heading 0 and state 0. `colorPaths` is setup-only. The source's saved rule widgets are intentionally distinct from example 1: the initial complete table is `[[1,180,true],[0,90,true],[0,0,true],[1,270,true]]`, in **off/state0, off/state1, on/state0, on/state1** order. All four rows are exposed through validated live state/turn/write widgets and the public tuple API `setRules`.

`go` retains the source's three distinct phases. First, **every** head computes its `ruleSet` from its old head state and the old tape. Second, heads write that frozen rule's tape value and path color; public `Random.sample(..., {compatibility:"legacy-shuffle"})` supplies a fresh permutation, so conflicting writes have a random last writer. Third, each head turns by its frozen rule, moves one periodic lattice cell, and enters its frozen next state. The temporary selected rule is canonical Agent state. No later head reads tape already changed by an earlier writer. Read/move phase order cannot change results, so their source-only random ask shuffles are omitted explicitly. The write permutation and color choices use Mulberry rather than NetLogo RNG; exact collision trajectories and seed identity are not claimed.

Canonical Grid fields also retain the source's numeric path color memory, because two on cells can have different last-writing head colors. `netLogoColor` is used only by UI projection. Head foreground colors are sampled from base color numbers; source create-turtle heading draws that are immediately overwritten are omitted. Dimensions must be odd. Head movement rebases cardinal orientation and snaps through public Grid/Agent APIs exactly as Vants does. All validation precedes mutation, including complete dense four-row rule validation.
