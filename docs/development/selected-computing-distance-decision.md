# B18 genotype distance boundary decision

Coordinator implementation decision, not independent approval. Source comparison establishes that the two named distances have different scientific meanings. Simple Genetic Algorithm measures binary locus mismatch divided by chromosome width, and composes it into its specified population diversity equation. Robby measures Euclidean distance between seven allele-frequency counts, with the source-specific273 display divisor, clipping and stale pre-mutation observations. Equal frequency vectors can describe entirely different strategies. Neither is a call to public spatial XY/XYZ geometry distance.

Keep the frozen `hammingDistance` export in the Simple Genetic Algorithm model as a publicly accessible **binary-genotype equation**, composed into this model's diversity procedure. Do not introduce an arbitrary sequence-distance library or a second copy for Robby. There is currently one demonstrated consumer of this exact genotype equation; speculative generalization would require new, unresolved equality/iterator/empty-input contracts. Revisit a focused public src capability when a second actual model needs that same mechanism. Source-specific model equations are permitted headless compositions; this decision does not authorize model-private reusable kernels.

The model export accepts two readonly, nonempty, equal-length binary-number arrays. Length is the modeled chromosome width; result is mismatching loci divided by that width. It returns0/1/.5/1/one-third for the five documented identical/complement/half/singleton/one-of-three scenarios. Empty, unequal-length, sparse, nonbinary or nonfinite arrays are outside a valid binary chromosome and must throw without mutation. No arbitrary iterable or object-equality behavior is added. Native source genomes always have positive equal world-width; validation therefore extends diagnostics, not the scientific transition. Preserve all original five frozen scripts and add these source-backed cases as supplemental assertions before resuming the paused equation implementation.

All remaining model APIs and runtime ownership remain with the scoped implementation thread. Canonical Graph edges own neural weights; hidden deltas use old outgoing weights before any update. No independent Argon approval is inferred from this decision; review remains quota-blocked.
