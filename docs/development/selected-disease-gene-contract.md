# Disease and genetics model contracts

The complete served XML in each owned experiment includes Procedures, Widgets, Info, shapes and preview. Inventory metadata, full widget XML, procedure inventories, extensions/includes and complete license/citation/credits notices are retained in selected-disease-gene-source-audit.json and each NOTICE.md. Archived bytes match inventory SHA-256 and pinned Galapagos git-blob SHA-1 at 90be931773fcf499049247a8aaa1aecbe003654c. Exact source hashes are required for comparison evidence. Loaded-session hashes and executed model behavior remain a separate browser gate.

Public models export create, inputs and model; instances expose advance(count=1), pure detached read(), setParameters for live widgets, and named headless source procedures/actions. Canonical World/Agent/Grid/Graph objects own state where applicable. Each source has its own explicit procedures; no shared whole-model engine. Random uses public Mulberry uniform/normal/exponential/Poisson, never a private MT implementation or trajectory-equivalence claim. Source sequence/complement/codon reactions are model equations. No new general library API is required by the audited closure. UI maps public functions into existing defineUI primitives only.

Diagnostic headless parameters deliberately admit infectionChance=0, averageRecoveryTime=1 and inoculationChance=100 for exact controlled mechanisms although epiDEM slider ranges are narrower. NetLogo command-center assignments permit these scenarios. UI should retain source widget ranges when practical; this declared extension does not change defaults/equations. Public example expectations must not be silently weakened.
