## Canonical state and public composition

All five factories retain their accepted create/advance/read syntax and existing observations. Each now exposes its canonical `world` through a getter without a setter; Galton Box, Binomial Rabbits and Stochastic Patchwork likewise expose `grid`. These are the actual public objects used by the procedures, not inspection copies. UI adapters remain unchanged: they read detached snapshots and invoke defined actions, never write these references.

Grid field arrays and the source's fixed block/counter selections cache references to canonical Fields once per instance. They contain no copied coordinates or competing mutable field values. Agent collections are obtained from World membership; there is no model-owned live population array. Temporary sorting/shuffling lists contain references to those same Agents and preserve the source phase's activation snapshot.

Galton's Field.color retains the source values 0 (black), 45 (yellow peg) and 52 (green minus 3 counter). yellowAt queries the canonical Field color. Counter labels/counts are the canonical Field.count value. The previous string-coordinate peg Set, array-backed counters and coordinate scans for ball occupancy are removed. The source's inclusive peg recursion and release → full/discard → no-falling preflight → randomized fall → counter update → tick sequence remain unchanged.

Rabbits translates the source's y=0..44 view to the public centered y=-22..22 Space. The model's scientific rabbit y=0 corresponds to canonical Agent.y=-22; the existing DTO continues exposing source y=0, preserving consumers and the existing UI translation. This is a constant coordinate-origin translation, not another position owner. No model performs modulo wrapping or manual coordinate-to-cell rounding. Its unwrapped displacement remains an intentional scientific variable, distinct from its wrapped spatial position. Field.turtleQuant is the source reporter's plot-phase cache, not an occupancy authority: Grid.agentsAt always answers current occupancy and updates when Agents move or are deleted.

## Identity, time and detached observations

Agent.id and Field.id are the globally unique framework identities. World membership, deletion, movement and Grid occupancy use canonical references/identities exclusively. Existing `read().people/racers/rabbits/particles/cells[].id` values remain deterministic local **display labels** projected from Agent/Field.displayId where applicable. They preserve accepted snapshots, replay examples and renderer keys; they are not domain identities, are not lookup keys for scientific rules, and are not a promise of equality with NetLogo who numbers. No second Agent/Grid implementation is introduced by these labels.

No canonical framework object or global ID leaks into read snapshots. Snapshots construct explicit frozen DTOs and arrays, so independent same-seed instances remain deeply equal despite different framework identities. Prior snapshots do not change when the canonical Agents/Fields advance. The World Tick remains the sole scientific time owner in every model; ordinary movement alone does not create another tick.

The existing Mulberry RNG, seeds, source draw thresholds and per-phase shuffles are retained. Framework creation/movement/deletion does not consume model RNG draws. Different RNGs and activation details between NetLogo and the target still prohibit a cross-engine trajectory-identity claim. Galton's preflight stop, Three Doors' within-phase done gate, Rabbits' exact-equality Go stop and all-zero-ratio behavior remain covered by the unchanged original behavior assertions.

The audited public contracts are sufficient: Agent.add with position/orientation, world.add, Agent.move with absolute/relative/distance forms, Agent.delete, Grid.add/fieldAt/agentsAt, World membership and run/Tick. No missing movement contract was encountered; no new core API, geometry primitive, private topology engine, dependency or UI capability was added.
