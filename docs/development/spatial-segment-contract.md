# Frozen spatial segment presentation contract

The actual Tijuana source draws road history through pen-down turtle movement; its default off display leaves white patches. The frozen headless Tijuana contract already emits ordered detached trace endpoints, numeric colors and source pen widths. A shared renderer must present these observations without owning movement, simulation time, population, trajectory generation or scientific caches. This is a UI-only additive capability, not a new headless modeling API.

Before renderer implementation, five asserted public authoring examples are frozen under examples/ui-segments with hashes. They cover public canonical movement projected as history, trace survival after Agent deletion, source-palette projection, cells/segments/agents together and legacy/empty/zero-width data. These scripts assert public data authoring and domain purity; they **do not execute a DOM renderer**. Actual rendering, layering, visibility, resizing and theme acceptance require separate Chromium pixel/screenshot checks. Type imports deliberately target not-yet-delivered UI exports at freeze; no stub export is created to hide that gap.

Add exported readonly SpatialSegment with from/to finite two-dimensional world-coordinate points, optional color and optional width. Add optional readonly segments to SpatialData. Endpoints use the same centered model coordinates as cells/agents. Width uses CSS pixels, matching existing symbol-size presentation; default1, zero omitted. Model adapters map headless trace numeric colors through public netLogoColor and pass widths through; this declared presentation scaling is not a scientific distance conversion. Missing color uses white. Source traces themselves retain source values. Existing GridData/SpatialData without segments remain compatible.

Draw cells first, ordered segments second and Agents/selection/labels last. Use the shared canvas world-to-buffer projection and CSS-pixel device ratio, without moving or inspecting live Agents. Do not silently discard stored nonzero segments. A stroke renders even after its source Agent dies. Respect zero width explicitly because Canvas ignores assignment of lineWidth0. Resize/theme rendering and disposal preserve existing interaction behavior. No mandatory wrapper, custom model canvas or UI-owned simulation state is introduced.

Runtime ownership is delegated only after this freeze commit to UI definition/export/canvas files. Preserve all five script assertions. The coordinator owns real Chromium proof with horizontal/vertical strokes, layering at an Agent center, zero-width omission, empty reset, desktop/mobile and themes, plus a keyboard/selection regression. Frontend-design and subsequent web-design-guidelines apply; current rules were fetched on6November2026. Required independent transfer approval remains separate and quota-blocked. No renderer execution is claimed at freeze.
