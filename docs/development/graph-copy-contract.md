# Independent graph copies

A graph copy gives an experiment its own topology while preserving the selected node identities. This contract defines independent `Graph.copy` results, edge-state cloning, selection and validation. It does not define `Graph.view` or a read-only graph facade. The public examples in `examples/graph-copy-proposal/` assert the behavior below.

Copies must meet these requirements:

- explicit arrays are identity-deduplicated membership filters; output preserves source entry insertion order. Omitted edges means induced edges, omitted nodes means all nodes. Every explicitly selected edge must have selected endpoints. Foreign/deleted entries reject.
- preserve existing parallel keys and representation flags; independent fresh automatic cursor starts0 and skips retained keys. Simple-to-undirected promotion preserves all connections, enables parallel only when required by collisions and assigns automatic keys in output order. Reverse changes only directed endpoints. Loops and all model states survive. No global opaque-ID continuity promise.
- independently clone owner defaults and each edge state using existing canonical clone semantics and separate sessions. Preserve aliases/cycles within each state and living framework identities, including references to the source owner/edges. Do not rebind framework references. Defaults clone even if no selected edges. Spatial paths require separate examples and coverage; graph copies do not fabricate them.
- hold source read guard through validation/reflection/preparation. Clone/validate everything, including final referenced-framework liveness, BEFORE constructing/publishing any target or Agent membership hooks. Reflection failure propagates and guards release; reject source mutation through reentrancy. Nested source queries and independent target edits are legal. No rollback of arbitrary Proxy external effects or concurrent impure direct model-field mutation. Test private participant registration on late failure, not just public topology.
- strict own data options, unknown/accessor/symbol keys reject without invoking getters. Recognized undefined means omission. Explicit selections are dense data arrays without extra own keys/accessors/symbols; array subclasses receive the same descriptor/Array.isArray checks, no new plain-array-prototype restriction. Validate option shapes, membership/endpoints, clones, publication in that order without a composite-invalid exact-message promise. No generator node/edge caps transfer. No public batch abstraction.

Use efficient internal prepared owner publication, not quadratic repeated public edges.add. Preserve all delivered kernel/generator/analyze/routing behavior and prior frozen scripts. New GraphCopyOptions is not required by the existing public signature; do not invent extra exported options unless implementation types need a named existing documented binding.
