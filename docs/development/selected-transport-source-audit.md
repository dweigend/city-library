## Paths

101×101 torus, coordinates −50…50. Setup creates 250 continuous-position walkers, each with a random patch goal; grass popularity starts zero. Each randomized walker activation either chooses another goal on arrival (buildings if at least two, otherwise any patch), or reinforces the current non-gray patch by 20 and faces its best visible route/destination, moving one unit. Visible gray patches within radius10 must be more than one unit closer to the destination than the walker; closest walker-distance wins with random ties. This is local perception, not graph shortest-path routing. After movement, unoccupied fields decay by4%; popularity below1 clears the route. Recoloring changes only non-gray fields, so route hysteresis matters. Threshold80, vision10, increment20, decay4 and show-popularity=false are live; walker-count is setup-only. Clicking removes all buildings within radius4 or creates one at the patch. No terminal condition, reporters or plots in source beyond tick.
