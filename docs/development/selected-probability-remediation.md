## Public composition rules

Scientific spatial populations use canonical public Agent instances; fields/topology use public Grid/Field instances; membership and the only persistent clock use World. Public Agent movement/orientation and Grid lookup/neighbors/occupancy replace private geometry/indexing. Cached arrays of canonical Field or Agent references may organize a source phase but never copy domain positions or occupancy authority. Model equations, source trial counters and numeric measurement histories remain ordinary model data.

Deterministic detached read DTOs preserve existing source/display labels so frozen independent-seed comparisons remain valid. These labels are not framework identity, membership keys or a domain lookup registry. Actual Agent.id/Field.id and canonical object references own identity. Canonical world/grid references are available through the headless instance for ownership tests. UI continues to invoke model actions only.

Combinations/permutations choices and guesses are symbolic trial vectors. Their static board coordinates are display DTOs, not a moving population; no unnecessary Agent objects are added for icons. Partition addend/current/previous vectors are numeric trial records, not spatial topology. Their scientific trial counters remain distinct from World.tick; the original tickless combination search remains tickless.

## Exact external closure needs

CLT requires the already-bound `stats.describe(values, { sample: true }).standardDeviation` for both sample-mean and sample-sum histories. Undefined spread at fewer than two samples maps to the existing null observation. No private standardDeviation/summary implementation is allowed. CLT closure remains pending until root supplies its public implementation commit. No Gaussian or other statistics expansion is requested here.

Mandelbrot needs the original full-step relocation rule and impossible-jump no-op rule. Delivered Agent.move clips a hard boundary and has no canMove/endpoint API. Named model procedures compose only public move/distanceTo operations: keep a temporary start DTO, attempt the move, compare traveled/requested distance, and restore through move({to:start}) when clipped, then apply the source rule. This introduces no private projection/trigonometry or persistent position authority; no observation callback runs between attempt and restoration. Exact boundary/numerical cases need focused tests and are explicitly reported for integration review. No new geometry API is introduced by this branch.
