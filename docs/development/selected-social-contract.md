## Common contract

Each experiment/model.ts exports inputs, create(options?) and model. Every instance exposes advance(count=1), pure detached read(), and setParameters(partial live options). Parameters use source names in camelCase, percentages retain source units; seed defaults to 1. Setup-only changes are rejected by setParameters, including unknown/accessor/symbol keys; validation is atomic before mutation/RNG/time. read includes tick, parameters, randomState, bounded history (initial plus at most 1000 latest samples), scientific state/reporters and stopped. No RNG/time mutation on reads. advance validates 0..1,000,000 integer count; a stop suppresses remaining batch calls. A later explicit advance may resume source preflight/run-stop behavior after controls change. No duplicate setup/live field in UI. Shared host Setup consumes current live values; Reset restores initial setup.

Source spatial coordinates retain patch-center coordinates in public snapshots; use canonical Grid/World/Agent translated through the existing public origin/space contracts. Views translate detached coordinates only as needed by centered renderer. Occupancy queries derive from canonical objects; do not maintain a second occupancy store. Shuffled source asks snapshot the activation set at each phase; nested calls may observe prior mutations. RNG uses public Random with explicit source distributions, independent from NetLogo MT; no cross-engine seed identity. Native semantic probes settle rounding and partial forward moves before relevant runtime assumptions are finalized.
