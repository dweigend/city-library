## Neural perceptron

[Complete audit](../../models/artificial-neural-net-perceptron/evidence/selected-computing/artificial-neural-net-perceptron-source.md). Four nodes (output, bias, input1,input2), three directed canonical Graph edges with mutable `weight`. Setup weights uniform [-.05,.05), bias activation 1, inputs/output initially random ±1 then output computed. Defaults learningRate .5, examplesPerEpoch 500, targetFunction xor, input1 1, input2 1, showWeights false. All widgets are live; training chooses random ±1 inputs per example, computes strict weighted-sum >0 (else -1), adds learningRate*(target-output)*input to each edge. Epoch error is squared signed error averaged then multiplied by .5 (range 0..2, not error proportion). One epoch ticks once; test sets inputs/propagates, reports expected/actual/correct without learning or ticking. All five truth functions or/xor/and/nor/nand. Public `test(a?,b?)`; `setScenario({weights:[bias,input1,input2],inputs:[a,b]})`. Read weights/activations, epochError, history and decision boundary; zero second weight cannot divide in target plotting: expose vertical/degenerate boundary explicitly rather than Infinity. Native plot division by zero is a documented source error, not a changed learning rule. Graph visualization fixed source positions; rule plot includes truth points. No terminal training condition.
