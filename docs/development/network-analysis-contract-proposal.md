# Graph analysis: five-measure public contract proposal

Status: **proposal only; no freeze or runtime handoff**, 6 November 2026. Scope is the already binding `graph.analyze` closure for degree, closeness, betweenness, eigenvector and PageRank, a concrete dependency of selected NW General Examples. This report adds five complete asserted public example proposals and bounded original-browser evidence. It changes no binding API, model source, delivered runtime, acceptance ledger or review gate.

## Existing binding and public boundary

The [API table](../agent-loom/api-table.md#graph-analyze) and [complete centrality contract](../agent-loom/api-reference.md#graph-centrality-extended) already specify:

```ts
graph.analyze(options: {
  measure: "degree" | "closeness" | "betweenness" | "eigenvector" | "pageRank";
  direction?: "out" | "in" | "all"; normalized?: boolean;
  disconnected?: "reachable" | "discount";
  cost?: (edge: Edge<N, E>) => number;
  weight?: (edge: Edge<N, E>) => number;
  damping?: number; tolerance?: number; maxIterations?: number
}): ReadonlyMap<N, number>
```

No renamed helper, new core public type, limited-measure stub or source-extension façade is proposed. The scripts use the existing public root `Graph`/`Edge` vocabulary; one purity witness uses already delivered Random/World. Current public Graph delivers neighbors/connectivity and the three recently delivered [distance methods](graph-distances-contract.md), but no analyze. Future accepted algorithms belong in focused graph algorithms, separate from the topology owner, with framework-independent maps and canonical node/edge references. UI consumes scores and model actions; it does not own a second centrality algorithm or topology.

A later implementation should use incidence accumulation for degree, positive-cost shortest-path traversals for closeness, Brandes-style dependency accumulation for betweenness, and the specified shifted-power/PageRank iterations. Repeated public distance calls must not accidentally recapture callbacks per source. Reuse the accepted shortest-path semantics and one captured query structure through an internal graph algorithm boundary; no new public preparer API is proposed. Exhaustive tiny-path enumeration below is only an independent oracle, not an implementation strategy.

Every result is a detached insertion-ordered ReadonlyMap containing **every canonical graph node**, including zero-score isolates; keys remain original identities. No query changes topology, model time or random stream. Readonly is an authoring contract, not a promise that freezing a Map magically disables `.set`; results must never expose an internal mutable cache.

## Preserved measure semantics and closed domains

| Measure | Exact existing meaning | Allowed optional fields / prohibited domains |
| --- | --- | --- |
| degree | Out by default. Undirected edge contributes1 to each endpoint in out/in/all; undirected loop contributes2. Directed loop contributes1 in out/in,2 in all. Sum incidences or finite nonnegative edge weights. normalized defaults false, true divides by max(1,n−1); scores above1 are valid. | direction, normalized, weight. Reject cost/disconnected/damping/tolerance/maxIterations. Weight callback explicitly once per edge. |
| closeness | Actual directed shortest paths, out default or in; cheapest parallel edge, strictly positive explicit costs. For r reachable peers, finite distance sum s: reachable=r/s, or0 when r=0; discount multiplies r/max(1,n−1). Default reachable. | direction out/in, disconnected reachable/discount, cost. Reject direction all, normalized, weight and iteration controls. No harmonic-centrality substitution. |
| betweenness | Fraction of shortest **vertex-simple** paths through each non-endpoint over ordered pairs; parallel-edge paths distinct. Halve for wholly undirected graphs. Positive explicit costs. normalized true divides by (n−1)(n−2), or half that for wholly undirected; n<3 yields zeros. Mixed directions stay arcs. | normalized, cost. Reject direction/disconnected/weight and iteration controls. Positive loops never enter a shortest vertex-simple path. |
| eigenvector | Incoming weighted adjacency; undirected edges supply both arcs, parallel weights add. Equal positive unit-L2 start, iterate (A+I), normalize L2, stop at L1 iterate change≤n×tolerance. Empty-edge nonempty graph returns zeros; otherwise nonconvergence throws. Default weight1/tolerance1e−9/maxIterations1000. | weight, tolerance, maxIterations. Reject direction/normalized/disconnected/cost/damping. Weights finite nonnegative. Zero effective adjacency and loop details remain U4/U5. |
| pageRank | Outgoing weighted transitions, parallel sums, zero weights ignored. Uniform start/teleport and uniform dangling-mass distribution; default damping.85 strictly(0,1), tolerance1e−9, maxIterations1000. Stop at L1 change≤n×tolerance; return total mass1, empty map for no nodes; nonconvergence throws. | weight, damping, tolerance, maxIterations. Reject direction/normalized/disconnected/cost. Finite positive tolerance and positive integer iteration bound. |

No hidden RNG, model-position influence, scientific-model validity claim or new JSON/cycle/resource limit follows from these operations. There is no specified 1024-node network-adapter cap on general graph analysis. A source extension's normalization is not grounds to change a bound public formula.

## Unresolved decisions before freeze

| ID | Question and proposed source-backed closure | Affected examples |
| --- | --- | --- |
| U1 | **One captured structure/cost/weight pass and callback purity.** degree explicitly evaluates weights once per edge; other analyze measures do not restate schedule. No local optional-field convention should silently change shared APIs. | 01 asserts degree cost/etc undefined still reject and allowed direction/normalized/weight undefined default correctly.
