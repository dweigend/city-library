# Public statistical summary implementation gate

The Economic Disparity original plots median rather than the Info's average, and the B17 CLT proposal contains a private generic standard-deviation helper. Reusable measurements belong to the public headless library. Existing stats exports only histogram/gini. This phase implements the already binding `stats.describe(values,options?)` contract in docs/agent-loom/api-reference.md#complete-statistics; it does not invent a new convenience API or deliver alignment/other distributions.

Public `stats.describe(values:Iterable<number>,options?:{sample?:boolean}):Summary`, samplefalse default. Export readonly Summary through src/stats/index.ts and the root index. Return frozen count,sum,min,max,mean,median,variance,standardDeviation. Empty count/sum0,otherfieldsundefined; singleton population spread0; sample spread undefined at n<2. Consume a finite iterable once,copy before sorting for median,preserve caller order. Even median is mean of middle pair. Population variance divides centered squared deviations by n,sample by n−1. Reject nonnumeric/nonfinite inputs,malformed/unknown/accessor options and nonfinite arithmetic,including sum or spread overflow; no mutation/RNG/World/renderer effect. Follow existing histogram/gini input-validation/error conventions. Validate options before iterating values.

Five asserted public examples in examples/summary are frozen before scoped runtime: unsorted population/even median;sample and degenerate values;one-shot iterable and detached output;invalid/options/overflow rejection;model-facing median and CLT sample spread. Preserve accepted syntax/expectations and existing stats API. Numerical formulas remain one owned pure kernel; consuming models select domain quantities and call it rather than maintaining private summary libraries. No stubs or speculative APIs.

Required checks: examples,higher-order/large-offset/property fixtures meaningful to summary behavior,all configured typechecks/build,existing examples and packed Bun/Node/ambient-free consumer with the new export. Independent technical approval is separately pending the recorded Antigravity quota blocker; implementation/test evidence must not be relabeled as that approval. Models may compose tested public runtime while retaining final review pending. Existing explicit Giant Component connectivity approval gate is unchanged.
