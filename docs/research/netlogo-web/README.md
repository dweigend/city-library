# NetLogo Web scientific research

Result: **200 complete, 0 incomplete**, 600 publication assignments. See [the complete index](INDEX.md), [machine-readable status](status.json) and [completion report](REPORT.md).

Scope: the immutable 200-model selection in `selection.json`, copied from the user-authorized selection. Research is separate from implementation, browser acceptance and independent implementation review.

Each `<slug>.json` is authoritative; `<slug>.md` is its human-readable companion. Schema version 1 contains `slug`, `name`, `catalogPath`, `launchUrl`, `deliveryBatch`, `status` (planned/in-progress/incomplete/complete), `miniText` (English, 100–160 whitespace-delimited words), `modelSource` (consulted URL, revision, checkedAt, evidence, notes), `publications` (exactly three for complete), and `gaps`. Publications contain `id`, `authors` (full names as verified), `title`, `year`, `venue`, `doi` (nullable), `url`, `relevance`, and `verification` (`consultedUrl`, `checkedAt`, `evidenceType`, `access`, `notes`). Only online-confirmed primary bibliographic metadata can be marked verified; abstract evidence is not full-text access. DOI registrant metadata counts as metadata only.

Publication relevance is model-specific. A shared work can support related models, but model provenance is additional to the three scientific publications. Simulation agreement does not establish empirical validity. Unresolved entries remain incomplete; no placeholder bibliography counts toward completion.

`status.json` and `INDEX.md` are regenerated by `validate.py`. Evidence snapshots may live in `evidence/`; batch working scripts/reports in `batches/`. All writes are restricted to this directory. No runtime or repository-wide documentation is changed.

## Evidence contract and integration

`verified: true` certifies checked bibliographic identity and the specifically recorded primary evidence tier. It does not certify full-text reading, empirical model validation or implementation acceptance. Author lists preserve the complete credited sequence and registered initials; given names are not expanded by guesswork. A missing DOI means no DOI was confirmed in the recorded checks; it is not an assertion that one can never exist.

Canonical local evidence fields are `modelSource.evidenceFile` and `publication.verification.evidenceFile`, relative to this directory. Additional batch-specific aliases are retained for traceability. `additionalEvidenceFiles` and consulted URLs describe supplementary checks, corrections or reading. Book reprints and historical editions are identified in evidence notes. Raw candidate-search files are not accepted publications unless referenced by an authoritative dossier.

Run `python docs/research/netlogo-web/validate.py` from the worktree to validate all dossier identities, counts, word limits, citations, retained evidence, original XML and source hashes, and regenerate the index/status ledger. This is an offline structural/evidence-integrity check, not a fresh network or scientific peer review.

The existing catalog and implementation ledger were read for identity/provenance context and were not changed. The four pre-existing reference models match their previously recorded served-source hashes exactly. Updates to runtime, catalog acceptance, commits and GitHub remain with the implementation coordinator.
