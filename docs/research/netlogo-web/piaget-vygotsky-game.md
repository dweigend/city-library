# Piaget-Vygotsky Game

Status: **complete** · Checked: 2026-11-05 · Mini-text: 123 words

The scientific question is whether individual feedback and social learning can complement one another. In NetLogo's Piaget-Vygotsky Game model, marble-rolling agents adjust their launch choices using personal performance, neighboring performance or both, approaching a common target. The selected literature connects this mechanism to explicit comparison of learning hypotheses: the original thought experiment operationalizes competing learning accounts [1]; collaborative critique changes the modeled social-learning relationship [2]; developmental constructivism supplies a theoretical background for individual adaptation [3]. Motor adjustment is a deliberately narrow learning proxy; mapping it onto developmental theories is contestable and does not validate an educational intervention. The original NetLogo behavior is the baseline for reimplementation. This simulation offers a controlled thought experiment, and agreement with its output does not establish empirical validation.
