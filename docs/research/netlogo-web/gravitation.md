# Gravitation

Research status: complete. Literature research only; implementation acceptance is separate.

NetLogo Gravitation investigates how a prescribed moving central mass shapes test-particle trajectories. Small particles accelerate toward a pointer-controlled large mass through an inverse-square attraction; the central mass and the small particles do not respond reciprocally. Provides the inverse-square mechanics; the record identifies a modern translation [1]. Provides a gravitational-integration benchmark for interpreting long-time orbital behavior [2]. Provides detailed central-force astrodynamics and orbital methods against which test-particle trajectories can be interpreted [3]. The source explicitly makes gravity one-way, with no small-particle interactions; moving the imposed attractor can exchange energy with particles, so an isolated-system conservation claim would be inappropriate. The simulation illustrates central-force trajectories and the importance of identifying which bodies actually participate in the dynamics. Reproducing these patterns establishes rule fidelity, not empirical validation.
