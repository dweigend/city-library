# Tree Simple

Status: complete. Scientific research checked 2026-11-05.

How can repeated branching produce a tree-like form? NetLogo Tree Simple uses agents as growing branch tips; recursive reproduction and turning generate smaller copies of a basic construction. Lindenmayer's original developmental formalism [1] supplies a scientific foundation for rule-based branching, the Algorithmic Beauty of Plants [2] develops turtle interpretations of plant grammars, and Chaos and Fractals [3] explains self-similarity and finite recursive approximations. The baseline is a geometric drawing experiment, with controls for the initial location, color changes, and repeated construction. Branch resemblance depends on the chosen rule and iteration depth. It does not include carbon allocation, mechanical support, resource competition, or measured botanical parameters. The simulation illustrates how hierarchical structure can emerge from a compact generative description; resemblance to a tree is not biological validation.
