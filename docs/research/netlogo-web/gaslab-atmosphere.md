# GasLab Atmosphere

Research status: complete. Literature research only; implementation acceptance is separate.

NetLogo GasLab Atmosphere investigates how gravity and collisions influence the vertical distribution and escape of gas. Particles receive downward acceleration, exchange velocities in elastic encounters, bounce from the ground and disappear when they cross the upper boundary. Supplies the molecular kinetic framework behind speed redistribution [1]. Analyzes the assumptions behind atmospheric density profiles [2]. Provides the collision-simulation reference for interpreting finite particle dynamics [3]. Gravity is constant, geometry is planar and the top is an absorbing numerical boundary; this is not a complete planetary exosphere or realistic atmospheric escape model. The simulation illustrates the competition between molecular motion, gravitational confinement and a finite escape boundary. Reproducing these patterns establishes rule fidelity, not empirical validation.
