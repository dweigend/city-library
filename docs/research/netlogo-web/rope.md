# Rope

Research status: complete. Literature research only; implementation acceptance is separate.

NetLogo Rope investigates how local elastic coupling transmits a driven disturbance along a string. Horizontally fixed nodes move vertically under neighboring spring-like forces, with a sinusoidally driven left end, a fixed right end and adjustable damping. Provides the classical string-vibration framework; the cited DOI is a later reissue [1]. Provides numerical stability context for discrete wave propagation [2]. Studies an interacting oscillator chain, offering a critical comparison about what linear coupling omits [3]. The baseline constrains motion to one transverse dimension and uses idealized coupling; a nonlinear oscillator-chain result is scientific context, not a claim that this rope implements that historical experiment. The simulation illustrates traveling waves, reflection, interference and the effects of damping and driving frequency. Reproducing these patterns establishes rule fidelity, not empirical validation.
