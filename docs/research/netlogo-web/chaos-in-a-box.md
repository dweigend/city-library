# Chaos in a Box

Research status: complete. Literature research only; implementation acceptance is separate.

NetLogo Chaos in a Box investigates why nearly identical initial trajectories can diverge in an obstacle-filled billiard. Noninteracting balls reflect elastically from fixed walls and circular obstacles, preserving speed while changing direction at each encounter. Develops the theory of dynamical systems with elastic reflections [1]. Shows how billiard geometry affects ergodic behavior [2]. Provides the broader deterministic-chaos context for sensitivity to initial conditions [3]. The source corrects overlaps after detecting collisions, so finite time steps introduce numerical effects; arbitrary obstacle arrangements need not all have the same rigorous chaotic properties. The simulation illustrates trajectory sensitivity without confusing deterministic motion with random forces. Reproducing these patterns establishes rule fidelity, not empirical validation.
