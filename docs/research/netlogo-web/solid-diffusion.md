# Solid Diffusion

Research status: complete. Literature research only; implementation acceptance is separate.

NetLogo Solid Diffusion investigates how random atomic exchanges smooth a concentration discontinuity between solids. The original diffusion-couple representation lets differently colored atoms mix through local motion and observes the resulting concentration profile. Provides the continuum concentration-gradient description against which mixing profiles can be interpreted [1]. Connects random microscopic motion with macroscopic diffusion [2]. Explains solid-state mechanisms and temperature-dependent transport absent from a generic random walk [3]. The lattice demonstration suppresses material-specific activation barriers, realistic crystal defects and independently measured transport coefficients. The simulation illustrates the difference between stochastic atomic rearrangement and average concentration transport. Reproducing these patterns establishes rule fidelity, not empirical validation.
