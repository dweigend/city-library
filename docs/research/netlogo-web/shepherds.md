# Shepherds

Status: complete. Scientific research only.

Which local transport rules can consolidate moving objects into a group? NetLogo Shepherds extends a termite-style clustering idea: wandering shepherds pick up sheep and release them near other sheep, while the sheep themselves also move. Collective sorting [1] and the StarLogo microworld lineage [2] provide the closest interpretation of these rules. A separate shepherding study [3] offers a useful comparison because actual herding need not involve carrying animals. Relative movement speeds and agent numbers can change whether aggregation persists. This is therefore an abstract experiment in clustering mobile objects, not a validated description of livestock management. A visible herd is evidence of the stated algorithm's behavior under chosen settings only.
