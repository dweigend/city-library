# Wave Machine

Research status: complete. Literature research only; implementation acceptance is separate.

NetLogo Wave Machine investigates how a driven membrane supports traveling and reflected waves. A rectangular array of vertically moving nodes interacts with four neighbors through spring-like forces; fixed edges reflect disturbances and a driver imposes sinusoidal displacement. Provides classical vibration and wave theory; the DOI identifies the Cambridge reissue [1]. Provides numerical discretization and stability context for lattice approximations to wave equations [2]. Provides a plate-mode comparison while highlighting that a spring membrane and a bending plate are different physical systems [3]. The source idealizes displacement to one direction and prescribes driver amplitude; time step, damping and lattice spacing constrain interpretation. The simulation illustrates superposition, reflection and the relation between local coupling and macroscopic wave patterns. Reproducing these patterns establishes rule fidelity, not empirical validation.
