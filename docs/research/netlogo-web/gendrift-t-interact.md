# GenDrift T interact

Status: complete. Scientific research only.

Can a population lose diversity without any color being advantageous? NetLogo GenDrift T Interact starts moving agents with several colors; neighboring encounters cause one agent to copy another's color. Colors that disappear cannot return. Finite-population drift [1], spatial copying processes [2], and neutral evolutionary theory [3] frame the resulting fixation and regional differences. The model's walls can isolate groups, altering which agents can interact. Color copying stands in for inherited variation rather than explicitly modeling mating, chromosomes, or reproduction. Consensus in a connected run illustrates stochastic loss under the specified interaction rules. It does not identify an adaptive benefit, establish that every spatial arrangement reaches global consensus, or reproduce a calibrated genetic history.
