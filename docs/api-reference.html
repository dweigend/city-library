City Library API reference

One reference for the whole system, arranged by the accepted target structure. Every entry shows its exact TypeScript signature, one status and a short contract. Source snapshot: 2026-11-11; no files have moved yet, so each module names its current path next to its target folder.

This page summarises and links. Detailed behaviour lives in the Agent Loom reference, the UI reference, the coverage page and the contracts under docs/development/. Where they disagree with the source, the exported source wins for availability.

A small model

A complete model uses only delivered API: walkers wander over a wrapped grid, warm the field they stand on, and heat spreads to neighboring fields. The model owns state, randomness and time; the UI only reads observations and calls model actions. Both files type-check against today's exports, and the model was run with Bun.

models/warm-walkers/model.ts

import { Agent, Grid, Random, World, run, stats } from "city-library";
import type { Definition, Inputs } from "../definition.ts";

export interface WarmWalkersParameters {
  seed: number;
  walkerCount: number;
}

export const inputs: Inputs<WarmWalkersParameters> = {
  seed: { kind: "number", default: 1, integer: true },
  walkerCount: { kind: "number", default: 12, min: 1, max: 50, integer: true },
};

export function create(options: Partial<WarmWalkersParameters> = {}) {
  const settings = {
    seed: inputs.seed.default,
    walkerCount: inputs.walkerCount.default,
    ...options,
  };
  const space = { x: 20, y: 20, boundary: "wrap" } as const;
  const random = Random.create({ seed: settings.seed });
  const world = World.create(space, { random });
  const grid = Grid.create(space, { state: { temperature: 0 } });
  const walkers = Array.from({ length: settings.walkerCount }, () =>
    Agent.create({}, { orientation: { heading: random.number({ max: 360 }) } }),
  );
  world.add([grid, ...walkers]);

  function step() {
    for (const walker of walkers) {
      walker.rotate(random.number({ min: -30, max: 30 }));
      walker.move();
      const field = grid.fieldAt(walker);
      if (field) field.temperature += 1;
    }
    grid.diffuse("temperature", { rate: 0.5 });
  }

  return {
    advance(stepCount = 1) {
      run(world, step, stepCount);
    },
    read() {
      const temperatures = grid.fields.map((field) => field.temperature);
      return {
        tick: world.tick.value,
        meanTemperature: stats.describe(temperatures).mean ?? 0,
        fields: grid.fields.map(({ id, x, y, temperature }) => ({ id, x, y, temperature })),
        walkers: walkers.map(({ id, x, y, heading }) => ({ id, x, y, heading })),
      };
    },
  };
}

export const model = {
  title: "Warm Walkers",
  description: "Walkers warm the field they stand on; heat spreads to neighbors.",
  inputs,
  create,
} satisfies Definition<WarmWalkersParameters, ReturnType<typeof create>>;

Conventions

These rules apply to every new entry. Delivered API keeps its frozen names and signatures where it predates a rule; see open decisions.

Naming
English, one canonical word per concept: agent, World, Grid and field, Graph and edge, tick, step, Agenda time, observation. camelCase members, PascalCase types, kebab-case folders and string codes, <noun>Count for counts. The core contains no application names such as city, traffic or economy. See naming conventions and domain and time semantics.
Stateful objects: Name.create(options)
A static factory creates a detached object; joining an owner is a separate add. 
const graph = Graph.create({ parallel: true });
world.add(graph);
Pure calculations are plain functions
They live in frozen namespaces and change nothing: stats.describe(values), geometry.distance(from, to, { space }), continuous.linear(input).
Every option is optional and playable
Omission gives a useful default: Grid.create() is 40 × 40, storage.history() keeps 300 samples. Required dependencies, such as the network of a city system, are the only exception. Nested options give finer control.
A function is the escape hatch
Pass a function where a fixed value is too rigid: graph.distances({ from, cost: (edge) => edge.length }), random.sample(items, { weight: (item) => item.size }).
Game-rule rejection
An action that a game rule refuses returns { ok: false, reason: "kebab-code" } and changes nothing, including Random state. The return type is the planned CommandResult; delivered core API has no game rules.
Misuse throws
TypeError for a wrong type, shape, unknown option or placeholder; RangeError for an out-of-range value. Validation happens before any change.
Observations are detached data
Model observations are readonly, JSON-serialisable plain data that never share state with the model. Library query results are detached too, but may use Map (for example graph.distances). Reading consumes no time and no randomness.
Explicit Random
Randomness comes from a Random the caller passes in. Nothing draws implicitly: construction consumes no randomness, and a World without a supplied stream uses its own seed-1 stream.
No globals or registries
No singletons, plugin registries, event buses or DSLs. Dependencies are function arguments, so a test can pass something else.

library-core

Autonomous, headless modules: no core module imports another. Shared semantics that cannot be duplicated live only in world-composition. Public names in index.ts are frozen; folder moves change no name. Pages: architecture, structure.
