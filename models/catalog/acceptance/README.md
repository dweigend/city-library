# Catalog acceptance records

These records compare catalog batches with their pinned sources and track cross-model checks. A batch report stays here once when its conclusions cover several models; model-specific probes, screenshots and reports live in the owning model's `evidence/` folder. The [progress ledger](../progress.json) identifies the evidence supporting each recorded stage.

Reports describe the checkout and commands recorded at the time. Navigation points to current owners or pinned Git revisions. Relocation and navigation repairs do not establish a new verification result or scientific acceptance. Immutable research/source references use [record paths](../record-paths.json). UI runtime checks belong to [Model Lab](../../../ui/model-lab/acceptance/), and shared core checks belong to [development verification](../../../docs/development/verification/).
