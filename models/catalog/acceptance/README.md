# Catalog acceptance records

These records compare catalog batches with their pinned sources and track cross-model checks. A batch report stays here once when its conclusions cover several models; model-specific probes, screenshots and reports live in the owning model's `evidence/` folder. The [progress ledger](../progress.json) identifies the evidence supporting each recorded stage.

Reports describe the checkout and commands recorded at the time. Original paths inside retained records resolve through [record paths](../record-paths.json); relocation does not establish a new verification result or scientific acceptance. UI runtime checks belong to [Agent Lab](../../../ui/agent-lab/acceptance/), and shared core checks belong to [development verification](../../../docs/development/verification/).
