# B07 source audit and binding model contracts

All ten archives were verified byte-for-byte against immutable inventory SHA-256 and pinned Galapagos `90be931773fcf499049247a8aaa1aecbe003654c` metadata before copying. Complete XML (code, widgets, Info, shapes, preview) and notices remain in each experiment. `selected-biology-source-audit.json` records every exact widget/procedure/default/topology and source digest. No extension/include dependency occurs. NetLogo 7.0.4 is the XML version, not an inferred running engine version.

Public models expose `create(options)`, instance `advance(count = 1)` and pure detached `read()`, live `setParameters` for audited live fields and named source actions/procedures. Each model definition uses existing Inputs/Definition and canonical validation. Public examples freeze the author-facing snapshots below. Seeds use existing Mulberry uniform/normal and explicit shuffled phases, not NetLogo MT trajectory equivalence. No new generic random/movement/grid/graph implementation is authorized.
