# Scarce Resource

Two applicants compete for one indivisible unit. Choose A or B explicitly; the first valid allocation consumes the inventory. Stale or foreign applicants are rejected without mutation. Setup creates a fresh independent allocation. Playback does not invent an allocation priority; use the allocation actions.

The headless [model](model.ts) owns state and actions; the shared Lab [UI](ui.ts) binds those actions and observations. Run `bun run dev`, select this model and use Setup. Original City Library teaching composition; no upstream scientific-equivalence claim.
