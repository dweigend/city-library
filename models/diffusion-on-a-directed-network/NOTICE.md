Implemented adaptation: readable headless TypeScript composes public Agent/World/Grid/Graph/Random/stats operations. Canonical edges retain active state and currentFlow even while inactive; rewire can reactivate the just-deactivated edge and does not advance tick/history or refresh the source's flow reporters. Mulberry replaces NetLogo's RNG for setup and rewiring. Deterministic insertion-order transport replaces source randomized ask order, consumes no RNG on go and stages all values before commit; floating summation roundoff can differ. Atomic quantity/active-link fixtures are additional interventions; the active-link fixture explicitly resets all flow values, unlike normal rewiring. Total-zero display values are guarded rather than dividing by zero. Histories retain setup plus latest 1000 completed steps. The existing shared network renderer uses an independent layout and neutral edge styling; a directed endpoint/flow table makes orientation inspectable, but source arrow/brightness presentation is not reproduced.

The single Rewire action is implemented. Source keep-rewiring requires an independent shared-host cadence and remains an explicit integration gap; no hidden timer or extra rewire per scientific tick is introduced. Source-specific behavior follows [the network contracts](../../docs/development/selected-network-contracts.md).
