# Response to the substantial independent review

The Antigravity gemini-3.8-flash review approved domain implementations, public contracts and scientific limitations, with conditional UI acceptance. Its report is retained verbatim in [independent-design-review.md](independent-design-review.md). It inspected earlier settled screenshots while presentation work continued. The following are coordinator responses, not independent reapproval.

1. Air/noise table precision: corrected with toFixed(3), toFixed(2) and toExponential(3). Five headers and horizontal scrolling were checked in the narrow UI; scrolling remains contained within the table.
2. Mobility: the graph now includes both car and walking links, with orange/blue colors identified in the caption and occupancy encoded in line width. The earlier claim that switching modes removed all edges was too broad: the old graph always retained its car links, but it omitted the walking link. A valid live carPenalty=5 plus Dispatch 4 trips now gives minute 1 with six moving and two waiting trips; the blue walking edge is visible and occupied. An earlier out-of-range input of 20 did not apply and is no longer reported as a successful policy intervention.
3. Economy: the tall preset and shorter firm/household labels had already been independently screenshot-approved in the later captures. The review-final set repeats all four viewports/themes for reinspection.
4. Housing: order="supplied" would render "supplied order" in the existing public collection projection; it would not remove the technical suffix and would impose an unnecessary ordering claim. The model now uses public count rows for home/status occupancy, with a readable household assignment/bid table. This retains the existing public projection API and avoids custom renderer code. Default and narrow/dark screenshots were repeated.

The initial review's statement about intact freeze-commit hashes needs qualification: there were no new commits. Scripts were frozen before runtime implementation. One throwing getter in the materials validation script received an editorial TypeScript return annotation; its assertions and expected failure did not change. The original hash necessarily differs, as already documented in that model's evidence. No independent report is rewritten to erase that qualification.

After the final UI corrections, bun run typecheck passed with zero errors/warnings; the focused housing/mobility tests passed (8 tests, 458 expectations), and bun run build:ui passed. The earlier full bun run check passed (835 tests, 352 scripts and packed consumers); later changes affect presentation and documentation only.

The subsequent [final independent review](final-independent-review.md) approved all four changed/rechecked UIs and accepted the housing-projection objection.
