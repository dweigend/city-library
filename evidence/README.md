# Source and acceptance records

These records support source attribution, comparisons and acceptance checks. They are not current usage instructions. Use the [documentation](../docs/README.md) for current behavior, contracts and planned work.

[Location metadata](locations.json) maps original repository paths to retained records. Artifact paths and checksums inside a record describe its original checkout. The [archive map](development/archive-paths.json) locates artifacts no longer kept locally. Relocation does not change acceptance stages or establish scientific validation.
