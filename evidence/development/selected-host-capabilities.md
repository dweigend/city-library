## NW: complete procedure and interaction closure

Code references below refer to the archived XML's `<code>` section; exact declaration line numbers are in the extraction.

`setup` clears agents, links, drawing, globals and plots, chooses the Degree distribution plot, defaults turtle shape to circle and resets ticks. World patch centers are −16…16 on each axis (33×33), hard boundaries in both directions, patch size 15, frame rate 30, update mode 1; the tick counter is hidden. There is **no `go`, tick increment or natural simulation termination**. Layout/highlight forever controls repeat actions at tick zero. Target hosting must preserve action semantics instead of inventing completed simulation steps.

| `layout` | spring; circle, radial, tutte | next layout invocation |

## GIS: complete procedure and interaction closure

World patch centers are x=−72…72, y=−36…36: 145×73 = 10585 patches; wrap on both axes, patch size 4, frame rate 30, update mode 0, tick counter shown. All 21 buttons are single observer actions, no forever control, plot or monitor. `setup` and `clear-drawing` work before initialized ticks; other buttons are disabled until ticks initialize. No action advances time, no `go`, no natural stop condition. The source creates several breeds with different lifetimes: country-labels, cities (`name`, `country`, `population`), citizens (`cntry_name`), plus ordinary star turtles. Patch values are `patch-population`, `country-name`, `elevation`; `country-name` is declared but never assigned by Code.

Inputs: projection chooser defaults `WGS_84_Geographic`, alternatives `US_Orthographic`, `Lambert_Conformal_Conic`; it is setup-only for loaded coordinate-system state. Changing it also changes the WMS branch immediately, so chooser and already loaded projection can diverge until next setup. Citizens count defaults 50, range 0…100 step 1, used on next create action. Numeric `lat=42.055`, `lon=−87.671` are live inputs to the next lat/lon creation. No source widget range validation is declared for lat/lon.

## Proposed smallest next decisions and example tasks

These are substantive scenario proposals, **not accepted syntax, runnable scripts or contract-frozen evidence**. Keep both complex selected models in scope; do not replace them with simplified graph/map demos.

1. **Context and topology authorship.** Freeze how one canonical graph preserves mixed breeds while selected analysis includes all nodes and one breed. Four/five asserted scripts should cover ring/star/wheel+lattice, append vs clear, context switching, zero/invalid counts, and exact edge direction. Audit NW generator parameters before implementing binding variants; keep Kleinberg and directed variants explicitly accountable.
